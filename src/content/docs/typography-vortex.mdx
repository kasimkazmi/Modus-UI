Sable's rotating typography vortex. Seeded rings of monospaced type are prerendered to bitmaps and spin at their own pace around an off-centre point, with drifting stray glyphs and dotted guide circles. The left edge constantly erodes into dust sampled from the actual glyph pixels. Moving the pointer carves a soft hole through the type and sheds matching dust; clicking pulls every particle into a brief suction sink. Dark and light modes rebuild the rings in their own ink. It pauses off screen, and pointer dissolve, dust and suction are switched off when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add typography-vortex
```

### Manual

1. Install `framer-motion`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/typography-vortex.tsx`.
4. Paste the code.

## Usage

```tsx
import { TypographyVortex } from "@/components/ui/typography-vortex";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <TypographyVortex phrase="MODUS / MOTION IN TYPE / " />
    </div>
  );
}
```

## Props

| Prop              | Type                | Default                               | Description                                          |
| :---------------- | :------------------ | :------------------------------------ | :--------------------------------------------------- |
| `mode`            | `"dark" \| "light"` | `"dark"`                              | Surface and ink colours.                             |
| `phrase`          | `string`            | `"SABLE / SYSTEMS IN MOTION / "`      | Text repeated around every ring.                     |
| `speed`           | `number`            | `1`                                   | Ring rotation speed multiplier.                      |
| `ringGrowth`      | `number`            | `1.21`                                | Radius ratio between neighbouring rings (min 1.08).  |
| `opacity`         | `number`            | `1`                                   | Overall opacity of the type, guides and dust.        |
| `dissolveRadius`  | `number`            | `1`                                   | Size multiplier of the hole carved by the pointer.   |
| `particleAmount`  | `number`            | `1`                                   | How much dust the pointer sheds.                     |
| `suctionDuration` | `number`            | `920`                                 | Length of the click suction in milliseconds.         |
| `hint`            | `string`            | `"MOVE / DISSOLVE · CLICK / SUCTION"` | Caption at the bottom; pass an empty string to hide. |
