---
title: Stub Pass
description: A perforated card with a primary-ink stub you can drag and tear clean off.
---

The body takes the card token and the stub is printed in the theme's primary, so the perforation reads as a clear seam in any palette. The card tilts toward the pointer and the stub resists before it rips.

<ComponentPreview name="stub-pass" />

## Installation

### CLI

```bash
npx @modus-ui/cli add stub-pass
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/stub-pass.tsx`.
3. Paste the code.

## Usage

```tsx
import { StubPass } from "@/components/ui/stub-pass";

export default function Example() {
  return (
    <StubPass stub={<span className="font-serif">14C</span>}>
      <span className="font-serif">The Quiet Press</span>
    </StubPass>
  );
}
```
