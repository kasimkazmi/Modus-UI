## Installation

### CLI

```bash
npx @modus-ui/cli add chime-switch
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/chime-switch.tsx`.
3. Paste the code.

## Usage

```tsx
import { ChimeSwitch } from "@/components/ui/chime-switch";

export default function Example() {
  return <ChimeSwitch />;
}
```
