---
title: ModeProvider
description: A React Native provider that holds the light, dark or system choice and exposes it through a useMode hook.
---

Holds the light, dark or system choice for the whole app. Read it anywhere below with `useMode()`. "system" follows the device and updates when the device changes. The provider keeps the choice in memory only; save it from `onModeChange` and pass it back as `initialMode` to remember it. Built for React Native and Expo with `react-native` only; this page previews it in the browser through react-native-web.

## Installation

### CLI

```bash
npx @modus-ui/cli add mode-provider
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/mode-provider.tsx`.
3. Paste the code.

It needs no packages beyond `react-native`, which your Expo or React Native app already has.

## Usage

```tsx
import { Pressable, Text } from "react-native";
import { ModeProvider, useMode } from "@/components/ui/mode-provider";

function ToggleButton() {
  const { scheme, toggle } = useMode();

  return (
    <Pressable onPress={toggle}>
      <Text>Currently {scheme}</Text>
    </Pressable>
  );
}

export default function App() {
  return (
    <ModeProvider>
      <ToggleButton />
    </ModeProvider>
  );
}
```

## Props

| Prop           | Type                   | Default    | Description                                           |
| :------------- | :--------------------- | :--------- | :---------------------------------------------------- |
| `initialMode`  | `Mode`                 | `"system"` | The mode to start in.                                 |
| `onModeChange` | `(mode: Mode) => void` | -          | Called whenever the mode changes, so you can save it. |

`useMode()` returns `mode`, the resolved `scheme`, `setMode(mode)` and `toggle()`, and throws outside a `ModeProvider`.
