A copy of `value` that only updates after it has stopped changing for `delay` milliseconds. Use it to wait out typing before searching: render with the live value, query with the debounced one. The first render returns the value straight away. Built for React Native and Expo with `react-native` only; this page previews it in the browser through react-native-web.

## Installation

### CLI

```bash
npx @modus-ui/cli add use-debounced-value
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/use-debounced-value.ts`.
3. Paste the code.

It needs no packages beyond `react-native`, which your Expo or React Native app already has.

## Usage

```tsx
import { useEffect, useState } from "react";
import { TextInput } from "react-native";
import { useDebouncedValue } from "@/components/ui/use-debounced-value";

export default function Search() {
  const [query, setQuery] = useState("");
  const debounced = useDebouncedValue(query, 400);

  useEffect(() => {
    if (debounced) console.log("search for", debounced);
  }, [debounced]);

  return <TextInput value={query} onChangeText={setQuery} />;
}
```

## API

| Part    | Type     | Default | Description                                      |
| :------ | :------- | :------ | :----------------------------------------------- |
| `value` | `T`      | -       | The value to debounce.                           |
| `delay` | `number` | `300`   | Milliseconds the value must stay still.          |
| Returns | `T`      | -       | The value as it was when the delay last ran out. |
