---
title: Character Carousel
description: A 3D carousel of profile cards, as an editorial filmstrip or a dark card wave.
---

Profile cards fan out in 3D around a focused card. Move the pointer to scrub, scroll or use the arrow keys to step, and click a card to bring it forward; after a few idle seconds the deck drifts on its own. The `wave` variant can also flip between a horizontal and a vertical wave (double-click or Space). It pauses off screen and snaps instead of easing when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add character-carousel
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/character-carousel.tsx`.
3. Paste the code.

## Usage

```tsx
import { CharacterCarousel } from "@/components/ui/character-carousel";

export default function Example() {
  return (
    <div className="relative h-[520px] w-full">
      <CharacterCarousel variant="wave" />
    </div>
  );
}
```

## Props

| Prop          | Type                      | Default                                      | Description                                                |
| :------------ | :------------------------ | :------------------------------------------- | :--------------------------------------------------------- |
| `variant`     | `"filmstrip" \| "wave"`   | `"filmstrip"`                                | An editorial filmstrip or a dark card wave.                |
| `items`       | `CharacterCarouselItem[]` | nine sample profiles with Unsplash portraits | Cards to show (`name`, `role`, `image`, optional `color`). |
| `speed`       | `number`                  | `1`                                          | Animation speed multiplier (0 to 2.5).                     |
| `scale`       | `number`                  | `1`                                          | Deck scale (0.7 to 1.3).                                   |
| `opacity`     | `number`                  | `1`                                          | Opacity of the scene (0.05 to 1).                          |
| `hue`         | `number`                  | `0`                                          | Hue rotation in degrees.                                   |
| `saturation`  | `number`                  | `1`                                          | Saturation multiplier.                                     |
| `brightness`  | `number`                  | `1`                                          | Brightness multiplier.                                     |
| `followLabel` | `string`                  | `"Follow me"`                                | Label on the wave variant's pill button.                   |
