---
title: Induction Button
description: A WebGL button wrapped in crawling cyan electric arcs that multiply on hover and discharge on click.
---

A raw-WebGL button whose rounded edge is traced by noisy cyan arcs over a kinetic grid field. Hover adds more arcs and clicking sends a synchronized discharge around the edge. It fills its positioned parent, pauses when off screen or when the tab is hidden, and holds a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add induction-button
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/induction-button.tsx`.
3. Paste the code.

## Usage

```tsx
import { InductionButton } from "@/components/ui/induction-button";

export default function Example() {
  return (
    <div className="relative h-[400px] w-full overflow-hidden">
      <InductionButton />
    </div>
  );
}
```

## Props

| Prop              | Type                                   | Default        | Description                                                                                  |
| :---------------- | :------------------------------------- | :------------- | :------------------------------------------------------------------------------------------- |
| `label`           | `string`                               | `"MODUS CORE"` | Button text.                                                                                 |
| `mode`            | `"dark" \| "light"`                    | `"dark"`       | Scene theme. The backdrop shader is colour-inverted when the mode differs from the original. |
| `hue`             | `number`                               | `0`            | Hue rotation in degrees (-180 to 180).                                                       |
| `saturation`      | `number`                               | `1`            | Saturation multiplier (0 to 2).                                                              |
| `brightness`      | `number`                               | `1`            | Brightness multiplier (0.35 to 1.65).                                                        |
| `darkBackground`  | `string`                               | `"#050505"`    | Scene colour in dark mode.                                                                   |
| `lightBackground` | `string`                               | `"#f4f7fb"`    | Scene colour in light mode.                                                                  |
| `onClick`         | `ButtonHTMLAttributes["onClick"]`      | -              | Called after the button's own click effect.                                                  |
| `onMouseEnter`    | `ButtonHTMLAttributes["onMouseEnter"]` | -              | Called after the button's own mouse enter effect.                                            |
| `onMouseLeave`    | `ButtonHTMLAttributes["onMouseLeave"]` | -              | Called after the button's own mouse leave effect.                                            |
| `onFocus`         | `ButtonHTMLAttributes["onFocus"]`      | -              | Called after the button's own focus effect.                                                  |
| `onBlur`          | `ButtonHTMLAttributes["onBlur"]`       | -              | Called after the button's own blur effect.                                                   |

Any other `<button>` attribute is passed through to the inner button.
