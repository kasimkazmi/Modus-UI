title: Letter Glitch
description: A canvas-rendered procedural matrix of glitching letters and symbols.
---

A highly-optimized canvas component that renders a dense grid of randomly fluctuating letters, smoothly transitioning between specified colors. Includes built-in center and edge vignette effects.

<ComponentPreview name="letter-glitch" />

## Installation

### CLI

```bash
npx @modus-ui/cli add letter-glitch
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/letter-glitch.tsx`.
3. Paste the code.

## Usage

```tsx
import { LetterGlitch } from "@/components/ui/letter-glitch";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full">
      <LetterGlitch
        glitchSpeed={50}
        centerVignette={true}
        outerVignette={true}
        smooth={true}
        glitchColors={["#f43f5e", "#8b5cf6", "#3b82f6"]}
      />
    </div>
  );
}
```

## Props

| Prop              | Type       | Default                                                         | Description                                           |
| :---------------- | :--------- | :-------------------------------------------------------------- | :---------------------------------------------------- |
| `glitchColors`    | `string[]` | `["#38bdf8", "#818cf8", "#34d399"]`                             | Colours the letters cycle through.                    |
| `glitchSpeed`     | `number`   | `50`                                                            | Milliseconds between glitch updates.                  |
| `centerVignette`  | `boolean`  | `true`                                                          | Darkens the centre with a radial vignette.            |
| `outerVignette`   | `boolean`  | `true`                                                          | Darkens the edges with a radial vignette.             |
| `smooth`          | `boolean`  | `true`                                                          | Fades between colours instead of switching instantly. |
| `lightMode`       | `boolean`  | `false`                                                         | Uses light-theme vignettes.                           |
| `backgroundColor` | `string`   | -                                                               | Canvas background colour.                             |
| `characters`      | `string`   | `"ABCDEFGHIJKLMNOPQRSTUVWXYZ!@#$&*()-_+=/[]{};:<>.,0123456789"` | Characters the grid is drawn from.                    |
