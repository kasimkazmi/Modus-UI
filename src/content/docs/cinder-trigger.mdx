---
title: Cinder Trigger
description: A commit button that burns down an undo window along its edge before it settles.
---

Cinder Trigger commits an action and then offers a short recall window, drawn as a line burning along the bottom edge. Hover pauses it and Escape recalls. Label type is mono uppercase, colours come from primary tokens. Ported from React Bits and restyled for Modus.

<ComponentPreview name="cinder-trigger" />

## Installation

### CLI

```bash
npx @modus-ui/cli add cinder-trigger
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/cinder-trigger.tsx`.
3. Paste the code.

## Usage

```tsx
import { CinderTrigger } from "@/components/ui/cinder-trigger";

export default function Example() {
  return <CinderTrigger />;
}
```

## Props

| Prop          | Type    | Default                          | Description                                                 |
| :------------ | :------ | :------------------------------- | :---------------------------------------------------------- |
| label         | string  | "Send proof"                     | Label before committing.                                    |
| undoLabel     | string  | "Recall"                         | Label while the undo window is open.                        |
| doneLabel     | string  | "Sent"                           | Label after the fuse burns out.                             |
| icon          | any     | -                                | Optional leading icon.                                      |
| color         | string  | "hsl(var(--primary-foreground))" | Text colour.                                                |
| background    | string  | "hsl(var(--primary))"            | Button background colour.                                   |
| fuseColor     | string  | "hsl(var(--primary-foreground))" | Colour of the burning fuse.                                 |
| size          | string  | "md"                             | Button size: "sm", "md" or "lg".                            |
| radius        | number  | 8                                | Corner radius in pixels.                                    |
| undoWindow    | number  | 4000                             | Time to undo in milliseconds.                               |
| fuse          | string  | "bottom"                         | Where the fuse burns: "outline", "top" or "bottom".         |
| fuseThickness | number  | 1.5                              | Fuse stroke width in pixels.                                |
| crossfadeMs   | number  | 200                              | Label crossfade duration in milliseconds.                   |
| commitOn      | string  | "press"                          | Fire onCommit on "press" or when the fuse ends ("fuseEnd"). |
| pauseOnHover  | boolean | true                             | Pause the fuse while hovered.                               |
| settle        | string  | "reset"                          | After finishing, "reset" to idle or "stay" done.            |
| disabled      | boolean | false                            | Disables the button.                                        |
| onCommit      | any     | -                                | Called when the action commits.                             |
| onUndo        | any     | -                                | Called when the action is undone.                           |
| onFuseEnd     | any     | -                                | Called when the fuse burns out.                             |
| onPhaseChange | any     | -                                | Called with each new phase.                                 |
| type          | string  | "button"                         | Native button type.                                         |
