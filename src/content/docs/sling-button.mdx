## Installation

### CLI

```bash
npx @modus-ui/cli add sling-button
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/sling-button.tsx`.
3. Paste the code.

## Usage

```tsx
import { SlingButton } from "@/components/ui/sling-button";

export default function Example() {
  return <SlingButton />;
}
```
