A two-line headline set inside a tilted ring of twelve 4:3 plates, each one flat colour shaded by a procedural field. The ring rests until a pointer is over it, then comes up to one orbit every 15 seconds and settles back to a stop on leave. Four galleries are included — matte (sprung), glitch, riso and halftone — each with its own palette, field, typeface and orbit. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add gallery-heading
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/gallery-heading.tsx`.
3. Paste the code.

## Usage

```tsx
import { GalleryHeading } from "@/components/ui/gallery-heading";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <GalleryHeading variant="horizontal-sweep" text={"NEW WORK\nON THE WALL"} />
    </div>
  );
}
```

## Props

| Prop              | Type                                                                               | Default             | Description                                                     |
| :---------------- | :--------------------------------------------------------------------------------- | :------------------ | :-------------------------------------------------------------- |
| `variant`         | `"rising-diagonal" \| "falling-diagonal" \| "horizontal-sweep" \| "vertical-loop"` | `"rising-diagonal"` | Matte, glitch, riso or halftone gallery.                        |
| `text`            | `string`                                                                           | —                   | Two-line headline split on `\n`. Defaults to the variant's own. |
| `mode`            | `"dark" \| "light"`                                                                | `"dark"`            | Black or paper stage, with matching ink.                        |
| `font`            | `"serif" \| "didone" \| "oldstyle" \| "sans"`                                      | —                   | Headline face. Defaults to the variant's face.                  |
| `weight`          | `"400" \| "700"`                                                                   | —                   | Headline weight. Defaults to the variant's weight.              |
| `headlineSize`    | `number`                                                                           | —                   | Headline size multiplier (0.6–1.8). Defaults to the variant's.  |
| `colors`          | `string[]`                                                                         | —                   | Twelve plate colours. Defaults to the variant's palette.        |
| `backgroundColor` | `string`                                                                           | —                   | Stage colour. Defaults to the mode's background.                |
| `hue`             | `number`                                                                           | `0`                 | Hue rotation of the final frame, in degrees.                    |
| `saturation`      | `number`                                                                           | `1`                 | Saturation of the final frame.                                  |
| `brightness`      | `number`                                                                           | `1`                 | Brightness of the final frame.                                  |
