A soft holographic gradient pill sits over two canvas starfields: a slow upward-drifting dust layer and coloured stars that wander, bounce and pulse with a glow. It fills its positioned parent, pauses when off screen or the tab is hidden, and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="star-portal" />

## Installation

### CLI

```bash
npx @modus-ui/cli add star-portal
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/star-portal.tsx`.
3. Paste the code.

## Usage

```tsx
import { StarPortal } from "@/components/ui/star-portal";

export default function Example() {
  return (
    <div className="relative h-[400px] w-full overflow-hidden">
      <StarPortal label="Begin the journey" href="/start" />
    </div>
  );
}
```

## Props

| Prop         | Type                                   | Default                        | Description                                                        |
| :----------- | :------------------------------------- | :----------------------------- | :----------------------------------------------------------------- |
| `label`      | `string`                               | `"Begin the journey"`          | Button text.                                                       |
| `mode`       | `"light" \| "dark"`                    | `"dark"`                       | Dark scene, or a light background with inverted starfields.        |
| `hue`        | `number`                               | `0`                            | Hue rotation in degrees (-180 to 180).                             |
| `saturation` | `number`                               | `1`                            | Saturation multiplier (0 to 2).                                    |
| `brightness` | `number`                               | `1`                            | Brightness multiplier (0.35 to 1.65).                              |
| `starColors` | `string[]`                             | Bronze, white, purple and blue | Star colours as open `rgba(r, g, b, ` prefixes; alpha is appended. |
| `href`       | `string`                               | `"#"`                          | Link target. `"#"` does not navigate.                              |
| `onClick`    | `MouseEventHandler<HTMLAnchorElement>` | -                              | Called when the portal link is clicked.                            |
