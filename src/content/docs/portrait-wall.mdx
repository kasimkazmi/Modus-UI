A wall of paper-toned portrait cards with serif names; colour returns only under the pointer. Ported from React Bits and refactored from GSAP to Framer Motion.

<ComponentPreview name="portrait-wall" />

## Installation

### CLI

```bash
npx @modus-ui/cli add portrait-wall
```

## Props

| Prop      | Type               | Default | Description                                                      |
| :-------- | :----------------- | :------ | :--------------------------------------------------------------- |
| items     | PortraitWallItem[] | -       | Array of items to render.                                        |
| radius    | number             | 300     | Radius of the hover spotlight effect.                            |
| columns   | number             | 3       | Maximum number of grid columns; narrow containers wrap to fewer. |
| rows      | number             | 2       | Number of grid rows; items beyond columns × rows are not shown.  |
| damping   | number             | 15      | Spring damping for the spotlight movement.                       |
| className | string             | -       | Classes merged onto the grid root.                               |
