title: Sylva World
description: A procedural moss-root world with pale flowers, ferns, drifting pollen, a scan-light entrance and a landing butterfly.
---

A Three.js scene where a moss-covered root arch is grown from geometry, with over a hundred thousand instanced moss blades, ferns, small white flowers and drifting pollen. A survey scan sweeps over it as it enters. Moving the pointer parts the moss, lifts a trail of pollen and shifts the camera. It fills its positioned parent, pauses when off screen or when the tab is hidden, and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add sylva-world
```

### Manual

1. Install `three`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/sylva-world.tsx`.
4. Paste the code.

## Usage

```tsx
import { SylvaWorld } from "@/components/ui/sylva-world";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <SylvaWorld />
    </div>
  );
}
```

## Props

| Prop              | Type             | Default                                                                 | Description                      |
| :---------------- | :--------------- | :---------------------------------------------------------------------- | :------------------------------- |
| `variant`         | `"living-green"` | `"living-green"`                                                        | Scene variant.                   |
| `backgroundColor` | `string`         | `"#4a4d44"`                                                             | Backdrop colour behind the moss. |
| `label`           | `string`         | `"Living green moss root with ferns, flowers, pollen, and a butterfly"` | Accessible label for the scene.  |
