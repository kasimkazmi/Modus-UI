---
title: Swipe Confirm
description: A drag-to-confirm track for actions that should not happen by accident.
---

The track sits on muted paper with a hairline border and mono caps. Return a promise from onConfirm to show a pending state, then a signed or failed state.

<ComponentPreview name="swipe-confirm" />

## Installation

### CLI

```bash
npx @modus-ui/cli add swipe-confirm
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/swipe-confirm.tsx`.
3. Paste the code.

## Usage

```tsx
import { SwipeConfirm } from "@/components/ui/swipe-confirm";

export default function Example() {
  return <SwipeConfirm />;
}
```
