title: Emblem Globe
description: A tiny dot-matrix globe that draws 23 marks in the theme ink, for a status pill or an avatar slot.
---

A small canvas globe that renders a mark as z-sorted, softly lit dots and keeps it gently moving, ideal next to a "Composing…" status label. The dots are recoloured in `--primary` (or any `color`) on a transparent surface, so it follows light, dark and every palette. Pick one of 23 marks and two sizes. It pauses when off screen or the tab is hidden and draws a still frame when the user prefers reduced motion.

## Installation

### CLI

```bash
npx @modus-ui/cli add emblem-globe
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/emblem-globe.tsx`.
3. Paste the code.

## Usage

```tsx
import { EmblemGlobe } from "@/components/ui/emblem-globe";

export default function Example() {
  return (
    <div className="h-14 w-14">
      <EmblemGlobe brand="ux" />
    </div>
  );
}
```

Available brands: `claude`, `openai`, `codex`, `cursor`, `gemini`, `figma`, `framer`, `react`, `swift`, `designcode`, `aura`, `dreamcut`, `ui`, `ux`, `css`, `ios`, `neuform`, `github`, `x`, `instagram`, `threads`, `linkedin`, `email`.

## Props

| Prop              | Type                                                                                                                                                                                                                                                                                                              | Default                 | Description                                          |
| :---------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------- | :--------------------------------------------------- |
| `brand`           | `"claude"` \| `"openai"` \| `"codex"` \| `"cursor"` \| `"gemini"` \| `"figma"` \| `"framer"` \| `"react"` \| `"swift"` \| `"designcode"` \| `"aura"` \| `"dreamcut"` \| `"ui"` \| `"ux"` \| `"css"` \| `"ios"` \| `"neuform"` \| `"github"` \| `"x"` \| `"instagram"` \| `"threads"` \| `"linkedin"` \| `"email"` | `"ui"`                  | Which mark to animate.                               |
| `size`            | `"small" \| "medium"`                                                                                                                                                                                                                                                                                             | `"medium"`              | `small` renders a 20px globe, `medium` a 56px globe. |
| `color`           | `string`                                                                                                                                                                                                                                                                                                          | `"hsl(var(--primary))"` | Dot colour; theme tokens are resolved.               |
| `speed`           | `number`                                                                                                                                                                                                                                                                                                          | `1`                     | Animation speed multiplier, clamped to 0.1–3.        |
| `paused`          | `boolean`                                                                                                                                                                                                                                                                                                         | `false`                 | Freezes the animation on its current frame.          |
| `backgroundColor` | `string`                                                                                                                                                                                                                                                                                                          | `"transparent"`         | Surface colour behind the globe.                     |
