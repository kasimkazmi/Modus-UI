title: Expanse Field
description: A stepped WebGL horizon of eleven breathing gradient bars with film grain.
---

A full-bleed Three.js shader of eleven stepped bars rising to a pale horizon, washed in a blue-to-pink gradient with animated film grain. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="expanse-field" />

## Installation

### CLI

```bash
npx @modus-ui/cli add expanse-field
```

### Manual

1. Install `three`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/expanse-field.tsx`.
4. Paste the code.

## Usage

```tsx
import { ExpanseField } from "@/components/ui/expanse-field";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <ExpanseField />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type                | Default     | Description                            |
| :---------------- | :------------------ | :---------- | :------------------------------------- |
| `mode`            | `"dark" \| "light"` | `"dark"`    | Colour scheme hint for the effect.     |
| `hue`             | `number`            | `0`         | Hue rotation in degrees (-180 to 180). |
| `saturation`      | `number`            | `1`         | Saturation multiplier (0 to 2).        |
| `brightness`      | `number`            | `1`         | Brightness multiplier (0.35 to 1.65).  |
| `baseColor`       | `string`            | `"#0a0a0f"` | Colour of the bars at the bottom.      |
| `startColor`      | `string`            | `"#1a4dcc"` | Gradient colour on the left side.      |
| `endColor`        | `string`            | `"#cc3380"` | Gradient colour on the right side.     |
| `horizonColor`    | `string`            | `"#f6f5f4"` | Colour above the stepped horizon.      |
| `backgroundColor` | `string`            | `"#07080b"` | Colour behind the effect.              |
