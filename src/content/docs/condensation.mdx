title: Condensation
description: Blue water droplets that bead up, merge and run down like condensation on dark glass.
---

A 2D canvas simulates droplets that grow in place, then run down, swallowing smaller drops in their path and splashing at the bottom edge. Drops are pale blue with a white highlight on a near-black background; every colour can be overridden. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="condensation" />

## Installation

### CLI

```bash
npx @modus-ui/cli add condensation
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/condensation.tsx`.
3. Paste the code.

## Usage

```tsx
import { Condensation } from "@/components/ui/condensation";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <Condensation />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type     | Default     | Description                                    |
| :---------------- | :------- | :---------- | :--------------------------------------------- |
| `speed`           | `number` | `1`         | Simulation speed multiplier.                   |
| `dropAmount`      | `number` | `1`         | Multiplier on the maximum number of droplets.  |
| `opacity`         | `number` | `1`         | Overall opacity of the droplets.               |
| `dropColor`       | `string` | `"#608bc4"` | Fill colour of each droplet.                   |
| `edgeColor`       | `string` | `"#466294"` | Outline colour of each droplet.                |
| `highlightColor`  | `string` | `"#ffffff"` | Specular highlight colour.                     |
| `splashColor`     | `string` | `"#4b6c9e"` | Colour of the splash rings at the bottom edge. |
| `backgroundColor` | `string` | `"#050507"` | Background behind the glass.                   |
