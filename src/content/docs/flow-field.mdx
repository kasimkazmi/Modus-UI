Warm amber, gold and coral particles trace a simplex-noise flow field and part around the pointer. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="flow-field" />

## Installation

### CLI

```bash
npx @modus-ui/cli add flow-field
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/flow-field.tsx`.
3. Paste the code.

## Usage

```tsx
import { FlowField } from "@/components/ui/flow-field";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <FlowField />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type       | Default                | Description                                              |
| :---------------- | :--------- | :--------------------- | :------------------------------------------------------- |
| `speed`           | `number`   | `1`                    | Animation speed multiplier.                              |
| `size`            | `number`   | `1`                    | Stroke width multiplier.                                 |
| `length`          | `number`   | `1`                    | Noise scale; higher values give longer, smoother curves. |
| `density`         | `number`   | `1`                    | Particle count multiplier (2500 at 1).                   |
| `opacity`         | `number`   | `1`                    | Canvas opacity.                                          |
| `hue`             | `number`   | `0`                    | Hue rotation in degrees.                                 |
| `saturation`      | `number`   | `1`                    | Saturation multiplier.                                   |
| `brightness`      | `number`   | `1`                    | Brightness multiplier.                                   |
| `colors`          | `string[]` | seven warm hex colours | Palette mapped across the noise field.                   |
| `backgroundColor` | `string`   | `"#0a0a0a"`            | Background and trail fade colour.                        |
