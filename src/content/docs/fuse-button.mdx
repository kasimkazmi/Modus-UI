## Installation

### CLI

```bash
npx @modus-ui/cli add fuse-button
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/fuse-button.tsx`.
3. Paste the code.

## Usage

```tsx
import { FuseButton } from "@/components/ui/fuse-button";

export default function Example() {
  return <FuseButton />;
}
```
