A dark glass pill with a flickering sparkle icon and letters that shimmer in sequence. On hover a coloured glow rises from below, and on focus the label blurs into a second label. Animations and transitions are turned off when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="generate-button" />

## Installation

### CLI

```bash
npx @modus-ui/cli add generate-button
```

### Manual

1. Install `framer-motion`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/generate-button.tsx`.
4. Paste the code.

## Usage

```tsx
import { GenerateButton } from "@/components/ui/generate-button";

export default function Example() {
  return <GenerateButton />;
}
```

## Props

| Prop          | Type                                   | Default        | Description                                         |
| :------------ | :------------------------------------- | :------------- | :-------------------------------------------------- |
| `label`       | `string`                               | `"Generate"`   | Resting label, animated letter by letter.           |
| `activeLabel` | `string`                               | `"Generating"` | Label shown after the button gains focus.           |
| `hue`         | `number`                               | `210`          | Hue of the hover, focus and press glow, in degrees. |
| `buttonColor` | `string`                               | `"#101010"`    | Button surface colour.                              |
| `onClick`     | `MouseEventHandler<HTMLButtonElement>` | `undefined`    | Click handler.                                      |
