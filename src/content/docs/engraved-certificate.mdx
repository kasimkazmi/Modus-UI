A paper certificate drawn on Canvas 2D: an engraved wave field and guilloche border, a medal of two rosettes and a slowly drifting harmonic pass. Every few seconds it switches to the next cam, redrawing the rosettes. It pauses off screen and stays still when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="engraved-certificate" />

## Installation

### CLI

```bash
npx @modus-ui/cli add engraved-certificate
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/engraved-certificate.tsx`.
3. Paste the code.

## Usage

```tsx
import { EngravedCertificate } from "@/components/ui/engraved-certificate";

export default function Example() {
  return (
    <div className="relative h-[560px] w-full">
      <EngravedCertificate label="Modus UI" title="Matrix 92 · Cam" />
    </div>
  );
}
```

## Props

| Prop              | Type     | Default             | Description                              |
| :---------------- | :------- | :------------------ | :--------------------------------------- |
| `label`           | `string` | `"Kinetic Lathe"`   | Small mono label above the medal.        |
| `title`           | `string` | `"Matrix 92 · Cam"` | Headline before the cam letter.          |
| `caption`         | `string` | `"Primary cam ·"`   | Caption before the cam letter.           |
| `inkColor`        | `string` | `"#1f3a30"`         | Engraving ink colour (hex).              |
| `paperColor`      | `string` | `"#f5efdf"`         | Certificate paper colour.                |
| `backgroundColor` | `string` | `"#ded6c2"`         | Scene background behind the certificate. |
| `cycleInterval`   | `number` | `4200`              | Milliseconds between cam changes.        |
