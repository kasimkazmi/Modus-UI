A clean button with a dual-gradient beam that animates smoothly across the perimeter, utilizing Framer Motion instead of custom tailwind config.

<ComponentPreview name="star-border" />

## Installation

### CLI

```bash
npx @modus-ui/cli add star-border
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/star-border.tsx`.
3. Paste the code.

## Usage

```tsx
import { StarBorder } from "@/components/ui/star-border";

export default function Example() {
  return <StarBorder color="rgba(168, 85, 247, 0.8)">Premium Button</StarBorder>;
}
```

## Props

| Prop              | Type                | Default                      | Description                             |
| :---------------- | :------------------ | :--------------------------- | :-------------------------------------- |
| `as`              | `React.ElementType` | `"button"`                   | Element to render as.                   |
| `color`           | `string`            | `"rgba(255, 255, 255, 0.8)"` | Colour of the moving star.              |
| `speed`           | `number`            | `6`                          | Seconds for one trip around the border. |
| `thickness`       | `number`            | `1`                          | Border thickness in pixels.             |
| `backgroundColor` | `string`            | `"hsl(var(--background))"`   | Inner background colour.                |
| `textColor`       | `string`            | `"hsl(var(--foreground))"`   | Text colour.                            |
| `borderColor`     | `string`            | `"hsl(var(--border))"`       | Colour of the static border.            |
