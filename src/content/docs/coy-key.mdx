---
title: Coy Key
description: A dashed mono key that edges away from the cursor until it relents.
---

Coy Key backs away from an approaching pointer inside its field, swapping its mono caption with every near miss, then gives in after a set patience. Ink and contrast follow the Modus theme. Ported from React Bits and restyled for Modus.

<ComponentPreview name="coy-key" />

## Installation

### CLI

```bash
npx @modus-ui/cli add coy-key
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/coy-key.tsx`.
3. Paste the code.

## Usage

```tsx
import { CoyKey } from "@/components/ui/coy-key";

export default function Example() {
  return <CoyKey />;
}
```
