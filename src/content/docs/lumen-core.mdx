A WebGL sphere set right of centre, veined with rotating fbm smoke and ringed by a soft halo, over a canvas of drifting motes. Its shading is a lightness ramp on the theme's primary hue: a glowing core on a dark background, an inked one on paper, following the palette picker. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion.

## Installation

### CLI

```bash
npx @modus-ui/cli add lumen-core
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/lumen-core.tsx`.
3. Paste the code.

## Usage

```tsx
import { LumenCore } from "@/components/ui/lumen-core";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <LumenCore />
      <div className="relative z-10 p-8 text-white">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type     | Default                    | Description                               |
| :---------------- | :------- | :------------------------- | :---------------------------------------- |
| `speed`           | `number` | `1`                        | Rotation speed multiplier.                |
| `scale`           | `number` | `1`                        | Scale of the core canvas.                 |
| `smokeScale`      | `number` | `1`                        | Size of the smoke detail.                 |
| `smokeStrength`   | `number` | `1`                        | Brightness of the smoke veil.             |
| `smokeSpeed`      | `number` | `1`                        | Speed of the smoke flow.                  |
| `hue`             | `number` | `0`                        | Hue rotation in degrees (core and motes). |
| `saturation`      | `number` | `1`                        | Orb colour saturation.                    |
| `glow`            | `number` | `1`                        | Strength of the rim and outer glow.       |
| `starDensity`     | `number` | `1`                        | Star count multiplier.                    |
| `starSpeed`       | `number` | `1`                        | Star drift speed.                         |
| `starSize`        | `number` | `1`                        | Star size multiplier.                     |
| `brightness`      | `number` | `1`                        | CSS brightness filter on the core.        |
| `opacity`         | `number` | `1`                        | Orb opacity.                              |
| `backgroundColor` | `string` | `"hsl(var(--background))"` | Colour behind the core.                   |
