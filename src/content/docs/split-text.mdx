Staggered text animations splitting by characters, words, or lines. A native Framer Motion implementation that achieves the same beautiful effect as GSAP's premium SplitText plugin without the cost or bundle size.

<ComponentPreview name="split-text" />

## Installation

### CLI

```bash
npx @modus-ui/cli add split-text
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/split-text.tsx`.
3. Paste the code.

## Usage

```tsx
import { SplitText } from "@/components/ui/split-text";

export default function Example() {
  return (
    <SplitText
      text="The details are not the details."
      delay={0.03}
      splitType="chars"
      className="font-serif text-3xl"
    />
  );
}
```

## Props

| Prop        | Type                                         | Default    | Description                                   |
| :---------- | :------------------------------------------- | :--------- | :-------------------------------------------- |
| `text`      | `string`                                     | -          | The text to animate.                          |
| `delay`     | `number`                                     | `0.05`     | Seconds between each segment.                 |
| `duration`  | `number`                                     | `0.5`      | Seconds each segment animates for.            |
| `splitType` | `"chars" \| "words" \| "lines"`              | `"chars"`  | How the text is split into segments.          |
| `threshold` | `number`                                     | `0.1`      | Fraction visible before the animation starts. |
| `textAlign` | `"left" \| "center" \| "right" \| "justify"` | `"center"` | Text alignment.                               |
| `as`        | `React.ElementType`                          | `"p"`      | Element to render as.                         |
