title: Newsletter Footer
description: A dark product footer with an inline newsletter form, an oversized closing phrase and compact legal links.
---

A dark footer with a numbered marker and blurb, a glass newsletter field whose button expands into an inline success state with an accent ring, a huge faint closing phrase and a row of legal links. All copy and links come from props, and `onSubmit` receives the entered email. Layout scales with the footer through container query units. Animations and transitions stop when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="newsletter-footer" />

## Installation

### CLI

```bash
npx @modus-ui/cli add newsletter-footer
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/newsletter-footer.tsx`.
3. Paste the code.

## Usage

```tsx
import { NewsletterFooter } from "@/components/ui/newsletter-footer";

export default function Example() {
  return (
    <div className="relative aspect-video w-full overflow-hidden">
      <NewsletterFooter onSubmit={(email) => console.log(email)} />
    </div>
  );
}
```

## Props

| Prop              | Type                                | Default                                                                                | Description                                       |
| :---------------- | :---------------------------------- | :------------------------------------------------------------------------------------- | :------------------------------------------------ |
| `marker`          | `string`                            | `"01"`                                                                                 | Text inside the square marker.                    |
| `description`     | `string`                            | `"A monthly edit of thoughtful interfaces,\npractical patterns, and new experiments."` | Blurb beside the marker; `\n` breaks the line.    |
| `placeholder`     | `string`                            | `"Email for monthly notes"`                                                            | Email field placeholder.                          |
| `buttonLabel`     | `string`                            | `"Join the list"`                                                                      | Submit button label.                              |
| `successLabel`    | `string`                            | `"You're subscribed"`                                                                  | Button label after a successful submit.           |
| `closingPhrase`   | `string`                            | `"STAY CURIOUS"`                                                                       | Oversized faint closing phrase.                   |
| `copyright`       | `string`                            | `"© 2026. Built for thoughtful work."`                                                 | Copyright text in the legal row.                  |
| `links`           | `{ label: string; href: string }[]` | Privacy, Terms and Contact anchors                                                     | Links in the legal row.                           |
| `onSubmit`        | `(email: string) => void`           | None                                                                                   | Called with the email when the form is submitted. |
| `backgroundColor` | `string`                            | `"#0a0a0a"`                                                                            | Footer background.                                |
| `accentColor`     | `string`                            | `"rgba(255, 194, 61, 0.5)"`                                                            | Ring colour shown in the success state.           |
| `style`           | `CSSProperties`                     | None                                                                                   | Inline styles for the footer.                     |
