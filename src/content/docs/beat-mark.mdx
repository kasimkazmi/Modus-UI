---
title: Beat Mark
description: A like button whose icon bursts and whose counter rolls on press.
---

The default is a squared mono pill with a star mark on the muted surface.

<ComponentPreview name="beat-mark" />

## Installation

### CLI

```bash
npx @modus-ui/cli add beat-mark
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/beat-mark.tsx`.
3. Paste the code.

## Usage

```tsx
import { BeatMark } from "@/components/ui/beat-mark";

export default function Example() {
  return <BeatMark />;
}
```
