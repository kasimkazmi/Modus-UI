---
title: Beat Mark
description: A like button whose icon bursts and whose counter rolls on press.
---

The default is a squared mono pill with a star mark on the muted surface.

<ComponentPreview name="beat-mark" />

## Installation

### CLI

```bash
npx @modus-ui/cli add beat-mark
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/beat-mark.tsx`.
3. Paste the code.

## Usage

```tsx
import { BeatMark } from "@/components/ui/beat-mark";

export default function Example() {
  return <BeatMark />;
}
```

## Props

| Prop         | Type    | Default                        | Description                               |
| :----------- | :------ | :----------------------------- | :---------------------------------------- |
| liked        | any     | -                              | Controlled liked state.                   |
| defaultLiked | boolean | false                          | Initial liked state when uncontrolled.    |
| count        | number  | 128                            | Count before your like.                   |
| onChange     | any     | -                              | Called with the new liked state.          |
| showCount    | boolean | true                           | Shows the rolling counter.                |
| icon         | string  | "star"                         | Mark shape: "star" or "heart".            |
| idleOutline  | boolean | true                           | Draws the idle mark as an outline.        |
| size         | number  | 40                             | Mark box size in pixels.                  |
| corner       | number  | 10                             | Pill corner radius in pixels.             |
| likedColor   | string  | "hsl(var(--primary))"          | Mark and burst colour when liked.         |
| idleColor    | string  | "hsl(var(--muted-foreground))" | Mark colour when idle.                    |
| pillColor    | string  | "hsl(var(--muted))"            | Pill background colour.                   |
| textColor    | string  | "hsl(var(--foreground))"       | Counter colour.                           |
| duration     | number  | 560                            | Pop and burst duration in milliseconds.   |
| dotSize      | number  | 0.3                            | Burst dot size as a fraction of the mark. |
| overshoot    | number  | 1.7                            | How far the mark overshoots as it pops.   |
| beat         | number  | 3                              | Burst dots per quarter turn.              |
| rollDuration | number  | 350                            | Counter roll duration in milliseconds.    |
| disabled     | boolean | false                          | Disables the button.                      |
| label        | string  | "Like"                         | Accessible label.                         |
