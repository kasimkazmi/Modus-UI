A small uppercase pill. On hover, a bright conic beam spins around its hairline border, the pill lifts and the arrow nudges forward. Animations and transitions are turned off when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="spinning-border-button" />

## Installation

### CLI

```bash
npx @modus-ui/cli add spinning-border-button
```

### Manual

1. Install `framer-motion`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/spinning-border-button.tsx`.
4. Paste the code.

## Usage

```tsx
import { SpinningBorderButton } from "@/components/ui/spinning-border-button";

export default function Example() {
  return <SpinningBorderButton />;
}
```

## Props

| Prop        | Type                                   | Default          | Description                         |
| :---------- | :------------------------------------- | :--------------- | :---------------------------------- |
| `label`     | `string`                               | `"Request Demo"` | Button text.                        |
| `beamColor` | `string`                               | `"#ffffff"`      | Colour of the spinning border beam. |
| `speed`     | `number`                               | `3`              | Seconds per beam rotation.          |
| `onClick`   | `MouseEventHandler<HTMLButtonElement>` | `undefined`      | Click handler.                      |
