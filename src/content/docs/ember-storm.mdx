A Three.js point vortex of 12,000 embers spiralling inward, white-hot at the core and cooling through amber to crimson, rendered at half resolution with screen blending. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="ember-storm" />

## Installation

### CLI

```bash
npx @modus-ui/cli add ember-storm
```

### Manual

1. Install `three`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/ember-storm.tsx`.
4. Paste the code.

## Usage

```tsx
import { EmberStorm } from "@/components/ui/ember-storm";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <EmberStorm />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type                | Default     | Description                            |
| :---------------- | :------------------ | :---------- | :------------------------------------- |
| `mode`            | `"dark" \| "light"` | `"dark"`    | Colour scheme hint for the effect.     |
| `hue`             | `number`            | `0`         | Hue rotation in degrees (-180 to 180). |
| `saturation`      | `number`            | `1`         | Saturation multiplier (0 to 2).        |
| `brightness`      | `number`            | `1`         | Brightness multiplier (0.35 to 1.65).  |
| `emberColor`      | `string`            | `"#b81a08"` | Colour of the cooling outer embers.    |
| `heatColor`       | `string`            | `"#ff8c1f"` | Colour of the hot embers.              |
| `coreColor`       | `string`            | `"#ffedc7"` | Colour of the white-hot vortex core.   |
| `backgroundColor` | `string`            | `"#080503"` | Colour behind the effect.              |
