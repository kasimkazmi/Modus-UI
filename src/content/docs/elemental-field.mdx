title: Elemental Field
description: A WebGL2 background where water ripples, lightning arcs or flames play around a mark, with pointer-driven interaction.
---

A full-bleed WebGL2 scene built around a signed distance field of a mark. Water refracts the mark beneath pointer-driven ripples, lightning crawls fBm arcs along its contour, and flame licks noise-driven tongues and embers upward from its edge. It fills its positioned parent, pauses when off screen or when the tab is hidden, and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add elemental-field
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/elemental-field.tsx`.
3. Paste the code.

## Usage

```tsx
import { ElementalField } from "@/components/ui/elemental-field";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <ElementalField variant="lightning" />
    </div>
  );
}
```

## Props

| Prop              | Type                                | Default                                                                                      | Description                                                |
| :---------------- | :---------------------------------- | :------------------------------------------------------------------------------------------- | :--------------------------------------------------------- |
| `variant`         | `"water" \| "lightning" \| "flame"` | `"water"`                                                                                    | Which element plays around the mark.                       |
| `markPath`        | `string`                            | `"M12 0C12.9 7 17 11.1 24 12C17 12.9 12.9 17 12 24C11.1 17 7 12.9 0 12C7 11.1 11.1 7 12 0Z"` | SVG path data in a 24×24 viewBox used as the central mark. |
| `speed`           | `number`                            | `1`                                                                                          | Animation speed multiplier (0 to 3).                       |
| `size`            | `number`                            | `1`                                                                                          | Mark size multiplier (0.65 to 1.5).                        |
| `particleAmount`  | `number`                            | `1`                                                                                          | Particle count multiplier (0 to 2).                        |
| `opacity`         | `number`                            | `1`                                                                                          | Canvas opacity (0.05 to 1).                                |
| `hue`             | `number`                            | `0`                                                                                          | Hue rotation in degrees (-180 to 180).                     |
| `saturation`      | `number`                            | `1`                                                                                          | Saturation multiplier (0 to 2).                            |
| `brightness`      | `number`                            | `1`                                                                                          | Brightness multiplier (0.35 to 1.8).                       |
| `backgroundColor` | `string`                            | `"#060708"`                                                                                  | Background colour behind the canvas.                       |
