---
title: Query Well
description: A composer for AI requests with sources, commands, model and effort menus.
---

It sits on the card surface with a hairline ring, and its send spark tints from the primary token.

<ComponentPreview name="query-well" />

## Installation

### CLI

```bash
npx @modus-ui/cli add query-well
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/query-well.tsx`.
3. Paste the code.

## Usage

```tsx
import { QueryWell } from "@/components/ui/query-well";

export default function Example() {
  return <QueryWell />;
}
```
