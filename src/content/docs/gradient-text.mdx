Seamlessly looping animated gradient text driven by `framer-motion` animation frames. Includes support for horizontal, vertical, and diagonal sweeps, and an optional gradient border tracing mode.

<ComponentPreview name="gradient-text" />

## Installation

### CLI

```bash
npx @modus-ui/cli add gradient-text
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/gradient-text.tsx`.
3. Paste the code.

## Usage

```tsx
import { GradientText } from "@/components/ui/gradient-text";

export default function Example() {
  return (
    <GradientText
      className="text-4xl font-bold"
      colors={[
        "hsl(var(--primary))",
        "hsl(var(--primary))",
        "hsl(var(--primary))",
        "hsl(var(--primary))",
      ]}
      animationSpeed={5}
    >
      Fluid Gradient Text
    </GradientText>
  );
}
```

## Props

| Prop             | Type                                       | Default                                                                                                               | Description                                           |
| :--------------- | :----------------------------------------- | :-------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------- |
| `colors`         | `string[]`                                 | `["hsl(var(--primary))", "hsl(var(--primary))", "hsl(var(--primary))", "hsl(var(--primary))", "hsl(var(--primary))"]` | Colours of the gradient.                              |
| `animationSpeed` | `number`                                   | `8`                                                                                                                   | Seconds for one gradient cycle.                       |
| `showBorder`     | `boolean`                                  | `false`                                                                                                               | Adds an animated gradient border.                     |
| `direction`      | `"horizontal" \| "vertical" \| "diagonal"` | `"horizontal"`                                                                                                        | Direction the gradient moves.                         |
| `pauseOnHover`   | `boolean`                                  | `false`                                                                                                               | Pauses the animation while hovered.                   |
| `yoyo`           | `boolean`                                  | `true`                                                                                                                | Reverses the animation each cycle instead of looping. |
