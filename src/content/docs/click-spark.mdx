A physics-based canvas effect that creates a burst of colorful sparks originating from the exact coordinates of a user's click.

<ComponentPreview name="click-spark" />

## Installation

### CLI

```bash
npx @modus-ui/cli add click-spark
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/click-spark.tsx`.
3. Paste the code.

## Usage

Wrap any container with `ClickSpark`.

```tsx
import { ClickSpark } from "@/components/ui/click-spark";

export default function Example() {
  return (
    <ClickSpark sparkColor="#0ea5e9" sparkCount={8}>
      <button>Click me for sparks</button>
    </ClickSpark>
  );
}
```

## Props

| Prop          | Type                                                   | Default                 | Description                             |
| :------------ | :----------------------------------------------------- | :---------------------- | :-------------------------------------- |
| `sparkColor`  | `string`                                               | `"hsl(var(--primary))"` | Colour of the sparks.                   |
| `sparkSize`   | `number`                                               | `10`                    | Length of each spark in pixels.         |
| `sparkRadius` | `number`                                               | `25`                    | Distance the sparks travel in pixels.   |
| `sparkCount`  | `number`                                               | `8`                     | Number of sparks per click.             |
| `duration`    | `number`                                               | `500`                   | Milliseconds the sparks last.           |
| `easing`      | `"linear" \| "ease-in" \| "ease-out" \| "ease-in-out"` | `"ease-out"`            | Easing of the spark motion.             |
| `extraScale`  | `number`                                               | `1`                     | Multiplier for spark distance and size. |
