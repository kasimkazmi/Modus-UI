A beautiful grid of cards that follow the cursor with a glowing spotlight, ported from React Bits and refactored from GSAP to Framer Motion.

<ComponentPreview name="chroma-grid" />

## Installation

### CLI

```bash
npx @modus-ui/cli add chroma-grid
```

## Props

| Prop      | Type             | Default      | Description                                |
| :-------- | :--------------- | :----------- | :----------------------------------------- |
| items     | ChromaGridItem[] | -            | Array of items to render.                  |
| radius    | number           | 300          | Radius of the hover spotlight effect.      |
| columns   | number           | 3            | Number of grid columns.                    |
| rows      | number           | 2            | Number of grid rows.                       |
| damping   | number           | 15           | Spring damping for the spotlight movement. |
| fadeOut   | number           | 0.6          | Duration of the fade out effect on leave.  |
| ease      | string           | "power3.out" | Easing function.                           |
| className | string           | ""           | -                                          |
