---
title: Koi Studies
description: A draggable stack of three koi cards over a swirling shader background, with pixel-tile reveals.
---

Three cards sit in a tilted stack inside slowly turning orbit rings. Drag left or tap for the next card, drag right for the previous one, or use the arrow keys. Each image is overlaid with a moving grid of hidden tiles that your cursor wipes away, and each new card inks its quote in word by word. A WebGL swirl with cursor ripples fills the background. Default images are koi photos from Wikimedia Commons (CC BY-SA); pass your own through `cards`. It pauses off screen and stays still when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add koi-studies
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/koi-studies.tsx`.
3. Paste the code.

## Usage

```tsx
import { KoiStudies } from "@/components/ui/koi-studies";

export default function Example() {
  return (
    <div className="relative h-[600px] w-full">
      <KoiStudies />
    </div>
  );
}
```

## Props

| Prop              | Type               | Default                                      | Description                                                                                       |
| :---------------- | :----------------- | :------------------------------------------- | :------------------------------------------------------------------------------------------------ |
| `cards`           | `KoiStudyCard[]`   | three koi studies (Kōhaku, Shūsui, Utsuri)   | The cards of the stack, front first (`name`, `seal`, `lines`, `image`, `panel`, `ink`, `accent`). |
| `hint`            | `string`           | `"← drag next · tap next · drag previous →"` | Hint under the stack.                                                                             |
| `backgroundColor` | `string`           | `"#10100e"`                                  | Scene background colour.                                                                          |
| `swirlColors`     | `[string, string]` | dark olive to warm taupe                     | Two colours of the swirling background shader.                                                    |
