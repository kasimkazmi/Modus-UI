---
title: Orbital Sphere
description: A WebGL sphere of 15,000 violet particles ringed by slowly turning orbits and glowing nodes.
---

A Three.js particle globe carved by noise, glowing with additive blending on a near-black stage, wrapped in six tilted orbit rings that drift in opposite directions. On wide screens it sits to the right of the frame. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="orbital-sphere" />

## Installation

### CLI

```bash
npx @modus-ui/cli add orbital-sphere
```

### Manual

1. Install `three`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/orbital-sphere.tsx`.
4. Paste the code.

## Usage

```tsx
import { OrbitalSphere } from "@/components/ui/orbital-sphere";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <OrbitalSphere />
      <div className="relative z-10 p-8">
        <h1>Content over the effect</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop               | Type     | Default     | Description                           |
| :----------------- | :------- | :---------- | :------------------------------------ |
| `speed`            | `number` | `1`         | Rotation speed multiplier.            |
| `particleSize`     | `number` | `0.015`     | Size of each particle.                |
| `particleOpacity`  | `number` | `0.8`       | Opacity of the particles.             |
| `orbitOpacity`     | `number` | `0.25`      | Opacity of the orbit rings.           |
| `scale`            | `number` | `1`         | Scale of the whole sphere.            |
| `haloOpacity`      | `number` | `0.2`       | Opacity of the glow around each node. |
| `hue`              | `number` | `0`         | Hue rotation in degrees.              |
| `particleColor`    | `string` | `"#a78bfa"` | Colour of the bright particles.       |
| `particleDimColor` | `string` | `"#701a75"` | Colour of the dim particles.          |
| `orbitColor`       | `string` | `"#8b5cf6"` | Colour of the orbit rings.            |
| `nodeColor`        | `string` | `"#d946ef"` | Colour of the orbiting nodes.         |
| `haloColor`        | `string` | `"#c084fc"` | Colour of the node halos.             |
| `backgroundColor`  | `string` | `"#030304"` | Background behind the sphere.         |
