A hacker-style text decryption matrix effect that scrambles text before revealing it. Can trigger on hover or when scrolled into view.

<ComponentPreview name="decrypted-text" />

## Installation

### CLI

```bash
npx @modus-ui/cli add decrypted-text
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/decrypted-text.tsx`.
3. Paste the code.

## Usage

```tsx
import { DecryptedText } from "@/components/ui/decrypted-text";

export default function Example() {
  return (
    <DecryptedText
      text="Hover over me to decrypt"
      animateOn="hover"
      speed={40}
      className="font-mono text-4xl"
    />
  );
}
```

## Props

| Prop                   | Type                           | Default                                                              | Description                                           |
| :--------------------- | :----------------------------- | :------------------------------------------------------------------- | :---------------------------------------------------- |
| `text`                 | `string`                       | -                                                                    | The text to reveal.                                   |
| `speed`                | `number`                       | `50`                                                                 | Milliseconds between scramble frames.                 |
| `maxIterations`        | `number`                       | `10`                                                                 | Scramble frames before revealing when not sequential. |
| `sequential`           | `boolean`                      | `false`                                                              | Reveals one character at a time.                      |
| `revealDirection`      | `"start" \| "end" \| "center"` | `"start"`                                                            | Where sequential reveal starts.                       |
| `useOriginalCharsOnly` | `boolean`                      | `false`                                                              | Scrambles using only the text's own characters.       |
| `characters`           | `string`                       | `"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz!@#$%^&*()_+"` | Characters used for scrambling.                       |
| `parentClassName`      | `string`                       | -                                                                    | Classes for the wrapper.                              |
| `encryptedClassName`   | `string`                       | -                                                                    | Classes for still-scrambled characters.               |
| `animateOn`            | `"view" \| "hover"`            | `"hover"`                                                            | Whether to run on hover or when scrolled into view.   |
| `delay`                | `number`                       | `0`                                                                  | Milliseconds to wait before starting.                 |
