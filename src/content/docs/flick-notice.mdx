---
title: Flick Notice
description: A card-stock notice that slides in, burns down a thin primary fuse and flicks away under a swipe.
---

The surface follows the theme's card and border tokens with a serif title, so it reads as a slip of paper rather than a system pill. Drag it past the swipe distance to dismiss, or hover to pause the fuse.

<ComponentPreview name="flick-notice" />

## Installation

### CLI

```bash
npx @modus-ui/cli add flick-notice
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/flick-notice.tsx`.
3. Paste the code.

## Usage

```tsx
import { FlickNotice } from "@/components/ui/flick-notice";

export default function Example() {
  return <FlickNotice title="Draft filed to the folio" />;
}
```
