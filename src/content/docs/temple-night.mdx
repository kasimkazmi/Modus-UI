A Three.js world with a temple hall, a torii gate and lanterns up a stone flight, maples, rain, mist and drifting leaves, finished with bloom and a colour grade that maps the moon, lantern light and fog onto the theme's primary hue, so it follows the palette picker and stays a night scene in light mode. It opens on a low, off-axis view up the stair. The camera follows the pointer. It fills its positioned parent, pauses when off screen or when the tab is hidden, and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add temple-night
```

### Manual

1. Install `three`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/temple-night.tsx`.
4. Paste the code.

## Usage

```tsx
import { TempleNight } from "@/components/ui/temple-night";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <TempleNight />
    </div>
  );
}
```

## Props

| Prop              | Type                    | Default          | Description                                                                      |
| :---------------- | :---------------------- | :--------------- | :------------------------------------------------------------------------------- |
| `variant`         | `"temple-night"`        | `"temple-night"` | Scene variant.                                                                   |
| `palette`         | `"modus" \| "original"` | `"modus"`        | `"modus"` grades the scene from theme tokens; `"original"` keeps the blood moon. |
| `backgroundColor` | `string`                | —                | Colour shown behind the canvas while loading. Defaults to the theme background.  |
| `className`       | `string`                | —                | Additional CSS classes.                                                          |
