A Canvas 2D busy-state button. A blue comet of light laps the border, a braille-dot spinner ticks beside the label, and a shimmer sweeps across the word. It fills its positioned parent, pauses when off screen or when the tab is hidden, and holds a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="thinking-button" />

## Installation

### CLI

```bash
npx @modus-ui/cli add thinking-button
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/thinking-button.tsx`.
3. Paste the code.

## Usage

```tsx
import { ThinkingButton } from "@/components/ui/thinking-button";

export default function Example() {
  return (
    <div className="relative h-[400px] w-full overflow-hidden">
      <ThinkingButton />
    </div>
  );
}
```

## Props

| Prop              | Type                       | Default                  | Description                                     |
| :---------------- | :------------------------- | :----------------------- | :---------------------------------------------- |
| `label`           | `string`                   | `"Thinking"`             | Word drawn on the button.                       |
| `mode`            | `"dark" \| "light"`        | `"dark"`                 | Picks the default background and plate colours. |
| `backgroundColor` | `string`                   | the mode's colour        | Scene background colour.                        |
| `plateColors`     | `[string, string, string]` | the mode's blue gradient | Plate gradient stops, top to bottom.            |
| `hue`             | `number`                   | `0`                      | Hue rotation in degrees (-180 to 180).          |
| `saturation`      | `number`                   | `1`                      | Saturation multiplier (0 to 2).                 |
| `brightness`      | `number`                   | `1`                      | Brightness multiplier (0.35 to 1.65).           |
