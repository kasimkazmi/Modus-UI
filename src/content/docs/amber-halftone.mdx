---
title: Amber Halftone
description: An animated amber-to-white Three.js point field rippling outward on a dark plane.
---

A grid of round WebGL points whose size pulses in rings from the centre, shaded from amber at the top to white at the bottom on a near-black plane. A light mode re-tones it to ink on paper. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add amber-halftone
```

### Manual

1. Install `three`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/amber-halftone.tsx`.
4. Paste the code.

## Usage

```tsx
import { AmberHalftone } from "@/components/ui/amber-halftone";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <AmberHalftone />
      <div className="relative z-10 p-8">
        <h1>Content over the effect</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type                | Default  | Description                                               |
| :---------------- | :------------------ | :------- | :-------------------------------------------------------- |
| `mode`            | `"dark" \| "light"` | `"dark"` | Amber on black, or ink on paper.                          |
| `speed`           | `number`            | `1`      | Ripple time multiplier (0–3).                             |
| `size`            | `number`            | `1`      | Point size multiplier.                                    |
| `length`          | `number`            | `1`      | Ripple wavelength multiplier; higher packs more rings.    |
| `density`         | `number`            | `1`      | Grid density; tightens point spacing (0.25–2.5).          |
| `color`           | `string`            | —        | Top gradient colour. Defaults to the mode's amber.        |
| `secondaryColor`  | `string`            | —        | Bottom gradient colour. Defaults to the mode's white/ink. |
| `backgroundColor` | `string`            | —        | Clear colour. Defaults to the mode's background.          |
| `hue`             | `number`            | `0`      | Hue rotation of the final frame, in degrees.              |
| `saturation`      | `number`            | `1`      | Saturation of the final frame.                            |
| `brightness`      | `number`            | `1`      | Brightness of the final frame.                            |
