## Installation

### CLI

```bash
npx @modus-ui/cli add hold-button
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/hold-button.tsx`.
3. Paste the code.

## Usage

```tsx
import { HoldButton } from "@/components/ui/hold-button";

export default function Example() {
  return <HoldButton />;
}
```
