---
title: Gateway Flow
description: Dotted bezier paths funnel particles into a central gateway; clicks send out shockwaves.
---

Dotted bezier curves sweep in from both edges and converge on the centre, each carrying a particle. Clicking sends a shockwave ring that pushes the particles aside. Click it to send a shockwave. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="gateway-flow" />

## Installation

### CLI

```bash
npx @modus-ui/cli add gateway-flow
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/gateway-flow.tsx`.
3. Paste the code.

## Usage

```tsx
import { GatewayFlow } from "@/components/ui/gateway-flow";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <GatewayFlow />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type                | Default         | Description                                                                      |
| :---------------- | :------------------ | :-------------- | :------------------------------------------------------------------------------- |
| `mode`            | `"dark" \| "light"` | `"dark"`        | Colour scheme of the original dark and light versions.                           |
| `speed`           | `number`            | `1`             | Animation speed multiplier (0–3).                                                |
| `size`            | `number`            | `1`             | Stroke / scale multiplier.                                                       |
| `density`         | `number`            | `1`             | Path count multiplier. (0.25–2.5).                                               |
| `opacity`         | `number`            | `1`             | Opacity of the effect layer (0.05–1).                                            |
| `hue`             | `number`            | `0`             | Hue rotation in degrees applied to the final frame.                              |
| `saturation`      | `number`            | `1`             | Saturation multiplier applied to the final frame.                                |
| `brightness`      | `number`            | `1`             | Brightness multiplier applied to the final frame.                                |
| `backgroundColor` | `string`            | mode background | Background colour behind the canvas (defaults to `#000000` in its default mode). |
