A dark section built around a floating device illustration set on drifting circuit dots, with a glowing pill label, an oversized gradient headline and a short supporting line. Typography scales with the section through container query units, so it fills its positioned parent at any size. The float and drift stop when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="editorial-intro" />

## Installation

### CLI

```bash
npx @modus-ui/cli add editorial-intro
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/editorial-intro.tsx`.
3. Paste the code.

## Usage

```tsx
import { EditorialIntro } from "@/components/ui/editorial-intro";

export default function Example() {
  return (
    <div className="relative aspect-video w-full overflow-hidden">
      <EditorialIntro title="Ideas, in motion." />
    </div>
  );
}
```

## Props

| Prop              | Type            | Default                                                                    | Description                         |
| :---------------- | :-------------- | :------------------------------------------------------------------------- | :---------------------------------- |
| `label`           | `string`        | `"Made for momentum"`                                                      | Text in the glowing pill label.     |
| `title`           | `string`        | `"Ideas, in motion."`                                                      | Oversized gradient headline.        |
| `description`     | `string`        | `"A focused interface keeps every action clear and every handoff moving."` | Supporting line under the headline. |
| `backgroundColor` | `string`        | `"#0a0a0a"`                                                                | Section background.                 |
| `style`           | `CSSProperties` | None                                                                       | Inline styles for the section.      |
