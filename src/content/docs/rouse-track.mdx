---
title: Rouse Track
description: A range input drawn as a field of bars that rise into a crest around the thumb.
---

Bars rest on the border token and fill with the primary ink up to the value, which is printed alongside. The crest follows the pointer and glides as you drag.

<ComponentPreview name="rouse-track" />

## Installation

### CLI

```bash
npx @modus-ui/cli add rouse-track
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/rouse-track.tsx`.
3. Paste the code.

## Usage

```tsx
import { RouseTrack } from "@/components/ui/rouse-track";

export default function Example() {
  return <RouseTrack ariaLabel="Leading" />;
}
```
