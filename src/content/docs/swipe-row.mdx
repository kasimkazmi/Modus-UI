## Installation

### CLI

```bash
npx @modus-ui/cli add swipe-row
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/swipe-row.tsx`.
3. Paste the code.

## Usage

```tsx

export default function Example() {
```
