---
title: Stream Convergence
description: A WebGL shader background of three converging red, green and blue light streams on black.
---

A full-bleed WebGL shader of three light streams that wave diagonally across a black field and overlap into violet and indigo. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="stream-convergence" />

## Installation

### CLI

```bash
npx @modus-ui/cli add stream-convergence
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/stream-convergence.tsx`.
3. Paste the code.

## Usage

```tsx
import { StreamConvergence } from "@/components/ui/stream-convergence";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <StreamConvergence />
      <div className="relative z-10 p-8 text-white">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type       | Default                  | Description                                                                |
| :---------------- | :--------- | :----------------------- | :------------------------------------------------------------------------- |
| `speed`           | `number`   | `1`                      | Animation speed multiplier.                                                |
| `fidelity`        | `number`   | `0.5`                    | Spread between the three streams.                                          |
| `scale`           | `number`   | `1`                      | Scale of the rendered canvas.                                              |
| `brightness`      | `number`   | `1`                      | CSS brightness filter.                                                     |
| `opacity`         | `number`   | `1`                      | Canvas opacity.                                                            |
| `hue`             | `number`   | `0`                      | Hue rotation in degrees.                                                   |
| `saturation`      | `number`   | `1`                      | CSS saturation filter.                                                     |
| `backgroundColor` | `string`   | `"#030304"`              | Background behind the canvas.                                              |
| `colors`          | `string[]` | Pure red, green and blue | One colour per stream; each is weighted like the original (1.2, 0.5, 1.8). |
