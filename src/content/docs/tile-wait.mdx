---
title: Tile Wait
description: A dot-grid progress indicator with a ticking timer and a mono caption.
---

Tiles ripple outward from the centre while work runs, then resolve into a check or a cross with the elapsed time. Colours follow `currentColor` and the Modus theme tokens.

<ComponentPreview name="tile-wait" />

## Installation

### CLI

```bash
npx @modus-ui/cli add tile-wait
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/tile-wait.tsx`.
3. Paste the code.

## Usage

```tsx
import { TileWait } from "@/components/ui/tile-wait";

export default function Example() {
  return <TileWait />;
}
```
