## Installation

### CLI

```bash
npx @modus-ui/cli add orbit-knob
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/orbit-knob.tsx`.
3. Paste the code.

## Usage

```tsx
import { OrbitKnob } from "@/components/ui/orbit-knob";

export default function Example() {
  return <OrbitKnob />;
}
```
