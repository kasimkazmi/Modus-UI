---
title: Tide Meter
description: A vertical level meter whose fill sloshes as it moves.
---

The vessel is a muted column with a hairline edge, filled with the primary colour and read out in mono numerals. Drag or use arrow keys to set the level.

<ComponentPreview name="tide-meter" />

## Installation

### CLI

```bash
npx @modus-ui/cli add tide-meter
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/tide-meter.tsx`.
3. Paste the code.

## Usage

```tsx
import { TideMeter } from "@/components/ui/tide-meter";

export default function Example() {
  return <TideMeter />;
}
```
