---
title: Pull Launch
description: A send button you can pull back like a slingshot and release.
---

A squircle pad in the primary colour stretches a band across a muted well, then fires a burst of particles when sent. Tapping or Enter sends too.

<ComponentPreview name="pull-launch" />

## Installation

### CLI

```bash
npx @modus-ui/cli add pull-launch
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/pull-launch.tsx`.
3. Paste the code.

## Usage

```tsx
import { PullLaunch } from "@/components/ui/pull-launch";

export default function Example() {
  return <PullLaunch />;
}
```
