A soft violet pill with a paper-white arrow disc. Hover lifts the capsule and slides the arrow. Ported from ThreeUI Community (MIT).

<ComponentPreview name="understory-arrow-pill" />

## Installation

### CLI

```bash
npx @modus-ui/cli add understory-arrow-pill
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/understory-arrow-pill.tsx`.
3. Paste the code.

## Usage

```tsx
import { UnderstoryArrowPill } from "@/components/ui/understory-arrow-pill";

export default function Example() {
  return (
    <div className="h-[400px] w-full">
      <UnderstoryArrowPill label="Begin" />
    </div>
  );
}
```

## Props

| Prop      | Type                                   | Default   | Description                                                      |
| :-------- | :------------------------------------- | :-------- | :--------------------------------------------------------------- |
| `label`   | `string`                               | `"Begin"` | Button text.                                                     |
| `mode`    | `"dark" \| "light"`                    | `"dark"`  | Ground the button is toned for; the stage background follows it. |
| `onClick` | `MouseEventHandler<HTMLButtonElement>` | —         | Click handler for the button.                                    |
