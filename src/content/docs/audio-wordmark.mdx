Two discs of rounded equaliser bars sit behind a bold wordmark and a row of small glyphs: the left disc's bars pulse, the right disc is a solid plate with bars cut through it. The wordmark tracks in from wide letter spacing each loop. It scales a 1080×1350 stage to fit its parent, pauses off screen and holds a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="audio-wordmark" />

## Installation

### CLI

```bash
npx @modus-ui/cli add audio-wordmark
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/audio-wordmark.tsx`.
3. Paste the code.

## Usage

```tsx
import { AudioWordmark } from "@/components/ui/audio-wordmark";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full">
      <AudioWordmark text="Modus UI" />
    </div>
  );
}
```

## Props

| Prop              | Type     | Default      | Description               |
| :---------------- | :------- | :----------- | :------------------------ |
| `text`            | `string` | `"Modus UI"` | Wordmark text.            |
| `accentColor`     | `string` | `"#7080ff"`  | Equaliser bar colour.     |
| `color`           | `string` | `"#E8EEE9"`  | Wordmark and icon colour. |
| `backgroundColor` | `string` | `"#000"`     | Scene background.         |
| `duration`        | `number` | `4.7`        | Loop length in seconds.   |
