A WebGL cathode-ray tube. Each variant paints its picture into an offscreen 2D canvas, then a fragment shader adds barrel curvature, scanlines, an aperture grille, chromatic fringing, phosphor halation, a rolling bar, flicker, grain and a vignette:

- `terminal` types out the green-phosphor ZION boot log with an amber status column and a blinking block cursor.
- `cinematic` is a monochrome film leader: a sweeping 8 to 2 countdown, scrolling perforations, registration marks and a running timecode, then a title card.
- `blue-screen` is a fault report with analogue tracking jitter, a rolling dropout band and a head-switching scramble.
- `nintendo` is a 320x180 pixel-art title screen, sampled with nearest filtering, where a runner jumps crates under a sweeping wordmark.

It pauses off screen. When the user prefers reduced motion it renders one still frame, with the terminal log fully typed. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add crt-screen
```

### Manual

1. Install `framer-motion`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/crt-screen.tsx`.
4. Paste the code.

## Usage

```tsx
import { CrtScreen } from "@/components/ui/crt-screen";

export default function Example() {
  return (
    <div className="relative h-[420px] w-full overflow-hidden">
      <CrtScreen variant="cinematic" />
    </div>
  );
}
```

## Props

| Prop         | Type                                                       | Default      | Description                                              |
| :----------- | :--------------------------------------------------------- | :----------- | :------------------------------------------------------- |
| `variant`    | `"terminal" \| "cinematic" \| "blue-screen" \| "nintendo"` | `"terminal"` | Which screen the tube shows.                             |
| `speed`      | `number`                                                   | `1`          | Time multiplier for the shader and animated screens.     |
| `typeSpeed`  | `number`                                                   | `1`          | Terminal typing speed multiplier.                        |
| `motion`     | `number`                                                   | `1`          | Strength of scanline drift, the rolling bar and flicker. |
| `brightness` | `number`                                                   | `1`          | CSS brightness applied to the whole tube.                |
| `opacity`    | `number`                                                   | `1`          | Opacity of the whole tube.                               |
| `hue`        | `number`                                                   | `0`          | Hue rotation in degrees.                                 |
| `saturation` | `number`                                                   | `1`          | CSS saturation multiplier.                               |
