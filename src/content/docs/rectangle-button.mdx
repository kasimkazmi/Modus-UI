One button family with 22 treatments, from dark glass and amber launch keys to dashed dot borders, rotating beams, glass access buttons and tactile keycaps. Each variant draws on the ground it was authored for, supports a light and dark mode, and keeps its own hover, focus and press motion. Animations stop when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="rectangle-button" />

## Installation

### CLI

```bash
npx @modus-ui/cli add rectangle-button
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/rectangle-button.tsx`.
3. Paste the code.

## Usage

```tsx
import { RectangleButton } from "@/components/ui/rectangle-button";

export default function Example() {
  return (
    <div className="h-[300px] w-full">
      <RectangleButton variant="meridian-keycap-primary" label="Start free" />
    </div>
  );
}
```

## Variants

`dark-pill`, `launch-button`, `dot-border-button`, `floating-dots-cta`, `sliding-text-cta`, `gradient-beam-cta`, `gradient-pill-button`, `generate-button`, `glassmorphism-cta`, `spinning-border-button`, `gradient-cta`, `lumen-cta`, `lumen-cta-ghost`, `trochil-signal`, `attune-thermal`, `tideform-outline`, `understory-arrow-pill`, `meridian-keycap-primary`, `meridian-keycap-secondary`, `halvorsen-arrow-pill`, `aster-glass-access`, `aster-glass-arrow`.

## Props

| Prop          | Type                             | Default                                                                               | Description                                          |
| :------------ | :------------------------------- | :------------------------------------------------------------------------------------ | :--------------------------------------------------- |
| `variant`     | `RectangleButtonVariant`         | `"dark-pill"`                                                                         | Which of the 22 treatments to render.                |
| `mode`        | `"light" \| "dark"`              | `"dark"`                                                                              | Ground the button is drawn on.                       |
| `label`       | `string`                         | Each variant's authored copy                                                          | Button text.                                         |
| `activeLabel` | `string`                         | `"Generating"`                                                                        | Text the Generate variant resolves to while focused. |
| `hue`         | `number`                         | `0`                                                                                   | Hue rotation in degrees (-180 to 180).               |
| `saturation`  | `number`                         | `1`                                                                                   | Saturation multiplier (0 to 2).                      |
| `brightness`  | `number`                         | `1`                                                                                   | Brightness multiplier (0.35 to 1.65).                |
| `background`  | `string`                         | The variant's authored stage colour                                                   | Overrides the stage background behind the button.    |
| `avatarSrc`   | `string`                         | `"https://images.unsplash.com/photo-1534528741775-53994a69daeb?w=128&h=128&fit=crop"` | Portrait shown in the Glassmorphism CTA.             |
| `avatarAlt`   | `string`                         | `"Advisor headshot"`                                                                  | Alt text for the portrait.                           |
| `onClick`     | `MouseEventHandler<HTMLElement>` | `undefined`                                                                           | Click handler.                                       |
