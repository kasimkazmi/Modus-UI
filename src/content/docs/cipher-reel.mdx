---
title: Cipher Reel
description: A one-time code field of paper slots with serif numerals that drop in and seal on success.
---

Cipher Reel is a one-time code field. A single hidden input does the typing, pasting and autofill, while serif numerals drop into paper slots; set `status` to seal the slots on success or shake them on error.

<ComponentPreview name="cipher-reel" />

## Installation

### CLI

```bash
npx @modus-ui/cli add cipher-reel
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/cipher-reel.tsx`.
3. Paste the code.

## Usage

```tsx
import { CipherReel } from "@/components/ui/cipher-reel";

export default function Example() {
  return <CipherReel />;
}
```

## Props

| Prop         | Type    | Default                     | Description                                               |
| :----------- | :------ | :-------------------------- | :-------------------------------------------------------- |
| length       | number  | 6                           | Number of slots.                                          |
| value        | any     | -                           | Controlled code.                                          |
| defaultValue | string  | ""                          | Initial code when uncontrolled.                           |
| onChange     | any     | -                           | Called with the code on every edit.                       |
| onComplete   | any     | -                           | Called once every slot is filled.                         |
| status       | string  | "idle"                      | "idle", "success" (slots seal) or "error" (field shakes). |
| mask         | boolean | false                       | Shows dots instead of digits.                             |
| caret        | boolean | true                        | Blinks a caret in the active slot.                        |
| disabled     | boolean | false                       | Disables input.                                           |
| autoFocus    | boolean | false                       | Focuses on mount.                                         |
| accentColor  | string  | `"hsl(var(--primary))"`     | Seal outline on success.                                  |
| inkColor     | string  | `"hsl(var(--foreground))"`  | Active slot outline and caret.                            |
| slotColor    | string  | `"hsl(var(--muted))"`       | Slot fill.                                                |
| digitColor   | string  | `"hsl(var(--foreground))"`  | Numeral colour.                                           |
| dangerColor  | string  | `"hsl(var(--destructive))"` | Outline on error.                                         |
| slotSize     | number  | `48`                        | Slot width in pixels.                                     |
| gap          | number  | `10`                        | Space between slots in pixels.                            |
| radius       | number  | `6`                         | Slot corner radius in pixels.                             |
| bounce       | number  | 0.2                         | Spring bounce as a digit lands.                           |
| settle       | number  | 0.3                         | Seal pulse duration in seconds.                           |
| rise         | number  | 8                           | Height digits drop from, in pixels.                       |
| cascade      | number  | 20                          | Delay between slots sealing, in milliseconds.             |
| ariaLabel    | string  | "One-time code"             | Accessible label.                                         |
