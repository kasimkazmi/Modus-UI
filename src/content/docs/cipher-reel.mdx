## Installation

### CLI

```bash
npx @modus-ui/cli add cipher-reel
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/cipher-reel.tsx`.
3. Paste the code.

## Usage

```tsx
import { CipherReel } from "@/components/ui/cipher-reel";

export default function Example() {
  return <CipherReel />;
}
```
