title: useKeyboardHeight

---

The height of the on-screen keyboard, or 0 while it is hidden. On iOS it updates as the keyboard starts to move, so a view can slide up alongside it; on Android it updates once the keyboard has finished appearing. It is always 0 on the web, where there is no on-screen keyboard to measure. Built for React Native and Expo with `react-native` only; this page previews it in the browser through react-native-web.

## Installation

### CLI

```bash
npx @modus-ui/cli add use-keyboard-height
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/use-keyboard-height.ts`.
3. Paste the code.

It needs no packages beyond `react-native`, which your Expo or React Native app already has.

## Usage

```tsx
import { TextInput, View } from "react-native";
import { useKeyboardHeight } from "@/components/ui/use-keyboard-height";

export default function Composer() {
  const keyboard = useKeyboardHeight();

  return (
    <View style={{ marginBottom: keyboard }}>
      <TextInput placeholder="Message" />
    </View>
  );
}
```

## API

| Part    | Type     | Description                                  |
| :------ | :------- | :------------------------------------------- |
| Returns | `number` | Keyboard height in points, or 0 when hidden. |
