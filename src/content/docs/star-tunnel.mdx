A WebGL flight down a corridor of letters, streaks, keycaps or rings, coloured from a ramp of the theme primary and foreground. It fills its positioned parent, follows the active theme and palette in light and dark mode, pauses when off screen and renders a still frame when the user prefers reduced motion.

<ComponentPreview name="star-tunnel" />

## Installation

### CLI

```bash
npx @modus-ui/cli add star-tunnel
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/star-tunnel.tsx`.
3. Paste the code.

## Usage

```tsx
import { StarTunnel } from "@/components/ui/star-tunnel";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <StarTunnel />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type                                                  | Default                              | Description                                       |
| :---------------- | :---------------------------------------------------- | :----------------------------------- | :------------------------------------------------ |
| `variant`         | `"streaks" \| "letters" \| "keycaps" \| "hyperspace"` | `"letters"`                          | Which corridor to fly through.                    |
| `speed`           | `number`                                              | `12`                                 | Distance travelled per frame.                     |
| `streakOpacity`   | `number`                                              | `0.6`                                | Opacity of the streaks (and keycap sparks).       |
| `tileOpacity`     | `number`                                              | `0.9`                                | Opacity of the tiles, letters, keycaps or tunnel. |
| `fov`             | `number`                                              | `62`                                 | Camera field of view in degrees.                  |
| `brightness`      | `number`                                              | `1`                                  | CSS brightness filter.                            |
| `hue`             | `number`                                              | `0`                                  | Hue rotation in degrees.                          |
| `saturation`      | `number`                                              | `1`                                  | CSS saturation filter.                            |
| `colors`          | `string[]`                                            | ramp of theme primary and foreground | Streak colours.                                   |
| `backgroundColor` | `string`                                              | theme background                     | Scene and fog colour.                             |
