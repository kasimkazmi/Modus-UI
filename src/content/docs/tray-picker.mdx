---
title: Tray Picker
description: A compact select whose tray slides open from its chip with serif options.
---

Tray Picker expands a single chip into a tray of options, keeps full keyboard support and sets each option in the Modus serif. Surfaces and highlights follow the active palette. Ported from React Bits and restyled for Modus.

<ComponentPreview name="tray-picker" />

## Installation

### CLI

```bash
npx @modus-ui/cli add tray-picker
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/tray-picker.tsx`.
3. Paste the code.

## Usage

```tsx
import { TrayPicker } from "@/components/ui/tray-picker";

export default function Example() {
  return <TrayPicker />;
}
```
