---
title: Tray Picker
description: A compact select whose tray slides open from its chip with serif options.
---

Tray Picker expands a single chip into a tray of options, keeps full keyboard support and sets each option in the Modus serif. Surfaces and highlights follow the active palette.

<ComponentPreview name="tray-picker" />

## Installation

### CLI

```bash
npx @modus-ui/cli add tray-picker
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/tray-picker.tsx`.
3. Paste the code.

## Usage

```tsx
import { TrayPicker } from "@/components/ui/tray-picker";

export default function Example() {
  return <TrayPicker />;
}
```

## Props

| Prop             | Type    | Default                  | Description                                    |
| :--------------- | :------ | :----------------------- | :--------------------------------------------- |
| options          | any     | DEFAULT_OPTIONS          | Options, as strings or option objects.         |
| value            | any     | -                        | Controlled selected value.                     |
| defaultValue     | any     | -                        | Initial value when uncontrolled.               |
| onChange         | any     | -                        | Called with the new value and option.          |
| placeholder      | string  | "Choose a face…"         | Text shown when nothing is selected.           |
| showTags         | boolean | true                     | Show option tags in the menu.                  |
| accentColor      | string  | "hsl(var(--foreground))" | Accent colour for the selection.               |
| surfaceColor     | string  | "hsl(var(--card))"       | Trigger and menu surface colour.               |
| highlightColor   | string  | "hsl(var(--muted))"      | Colour of the gliding highlight.               |
| textColor        | string  | "hsl(var(--foreground))" | Text colour.                                   |
| size             | string  | "md"                     | Trigger size: "sm", "md" or "lg".              |
| radius           | number  | 10                       | Corner radius in pixels.                       |
| menuWidth        | number  | 176                      | Menu width in pixels.                          |
| placement        | string  | "bottom"                 | Open the menu "bottom" or "top".               |
| align            | string  | "left"                   | Align the menu "left" or "right".              |
| popDuration      | number  | 180                      | Menu open duration in milliseconds.            |
| glideDuration    | number  | 220                      | Highlight glide duration in milliseconds.      |
| rememberPosition | boolean | true                     | Keep the highlight on the last hovered option. |
| disabled         | boolean | false                    | Disables the picker.                           |
| ariaLabel        | string  | "Choose"                 | Accessible label for the trigger.              |
