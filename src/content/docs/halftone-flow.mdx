A flowing field resolved through a halftone dot matrix, with a red-orange shader variant and an amber Three.js point-field variant. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="halftone-flow" />

## Installation

### CLI

```bash
npx @modus-ui/cli add halftone-flow
```

### Manual

1. Install `three`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/halftone-flow.tsx`.
4. Paste the code.

## Usage

```tsx
import { HalftoneFlow } from "@/components/ui/halftone-flow";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <HalftoneFlow />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type                    | Default              | Description                                                               |
| :---------------- | :---------------------- | :------------------- | :------------------------------------------------------------------------ |
| `variant`         | `"halftone" \| "amber"` | `"halftone"`         | Which halftone renderer to show.                                          |
| `mode`            | `"dark" \| "light"`     | `"dark"`             | Colour scheme for the amber variant.                                      |
| `speed`           | `number`                | `1`                  | Animation speed multiplier.                                               |
| `size`            | `number`                | `1`                  | Point size multiplier (amber).                                            |
| `length`          | `number`                | `1`                  | Wave frequency multiplier (amber).                                        |
| `density`         | `number`                | `1`                  | Point density (amber).                                                    |
| `opacity`         | `number`                | `1`                  | Canvas opacity (amber).                                                   |
| `hue`             | `number`                | `0`                  | Hue rotation in degrees.                                                  |
| `saturation`      | `number`                | `1`                  | Saturation multiplier.                                                    |
| `brightness`      | `number`                | `1`                  | Brightness multiplier.                                                    |
| `colors`          | `string[]`              | depends on `variant` | Hex colours: dark, red and bright for halftone; top and bottom for amber. |
| `backgroundColor` | `string`                | depends on `variant` | Background colour.                                                        |
