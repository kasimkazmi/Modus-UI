title: Outline Typeflow
description: A sentence flowing around the outline of an SVG mark, drawn on canvas.
---

A mark's outline sampled as one path, with a sentence running its full length. Hover to speed it up, click to shove the letters outward. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="outline-typeflow" />

## Installation

### CLI

```bash
npx @modus-ui/cli add outline-typeflow
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/outline-typeflow.tsx`.
3. Paste the code.

## Usage

```tsx
import { OutlineTypeflow } from "@/components/ui/outline-typeflow";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <OutlineTypeflow />
    </div>
  );
}
```

## Props

| Prop              | Type                | Default                                                                         | Description                                     |
| :---------------- | :------------------ | :------------------------------------------------------------------------------ | :---------------------------------------------- |
| `path`            | `string`            | `"M12 2a10 10 0 1 1 0 20a10 10 0 1 1 0-20Zm0 5a5 5 0 1 0 0 10a5 5 0 1 0 0-10Z"` | SVG path data (24×24 viewBox) the type follows. |
| `text`            | `string`            | `"modusreadsthepathandwritesitbackagain"`                                       | Phrase running along the outline.               |
| `mode`            | `"dark" \| "light"` | `"dark"`                                                                        | Colour scheme of the ground and ink.            |
| `scale`           | `number`            | `1`                                                                             | Scales the drawing (clamped 0.65–1.5).          |
| `opacity`         | `number`            | `1`                                                                             | Overall opacity (clamped 0.1–1).                |
| `hue`             | `number`            | `0`                                                                             | Hue rotation in degrees (clamped -180–180).     |
| `saturation`      | `number`            | `1`                                                                             | Saturation multiplier (clamped 0–2).            |
| `brightness`      | `number`            | `1`                                                                             | Brightness multiplier (clamped 0.4–1.8).        |
| `inkColor`        | `string`            | Mode ink (`#e2e4e9` dark, `#262830` light)                                      | Colour of the type, as hex.                     |
| `backgroundColor` | `string`            | Mode ground (`#08090a` dark, `#f3f5f8` light)                                   | Background colour.                              |
