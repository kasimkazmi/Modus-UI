---
title: Glance Score
description: A rating row whose icons lift as you hover, with a mono label tip.
---

Unset marks sit in the border tone, filled marks take the primary colour and the tip prints in inverted ink.

<ComponentPreview name="glance-score" />

## Installation

### CLI

```bash
npx @modus-ui/cli add glance-score
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/glance-score.tsx`.
3. Paste the code.

## Usage

```tsx
import { GlanceScore } from "@/components/ui/glance-score";

export default function Example() {
  return <GlanceScore />;
}
```
