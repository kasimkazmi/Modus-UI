Softly pulsing pale gold nodes drift across a 2D canvas on a deep navy background, linked by hairlines when they come close and pulled gently toward the pointer. Set `mode="light"` for bronze ink on pale paper, or override `color` and `backgroundColor`. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add constellation-field
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/constellation-field.tsx`.
3. Paste the code.

## Usage

```tsx
import { ConstellationField } from "@/components/ui/constellation-field";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <ConstellationField />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type                | Default           | Description                                                            |
| :---------------- | :------------------ | :---------------- | :--------------------------------------------------------------------- |
| `mode`            | `"dark" \| "light"` | `"dark"`          | Colour scheme: pale gold on navy, or bronze on pale paper.             |
| `speed`           | `number`            | `1`               | Drift and pulse speed multiplier (0 to 3).                             |
| `size`            | `number`            | `1`               | Node radius multiplier.                                                |
| `length`          | `number`            | `1`               | Link distance multiplier (base 160px, 0.35 to 2.5).                    |
| `density`         | `number`            | `1`               | Node count multiplier (85 nodes on wide hosts, 40 under 768px).        |
| `strokeWidth`     | `number`            | `1`               | Link line width in pixels.                                             |
| `opacity`         | `number`            | `1`               | Opacity of nodes and links (0.05 to 1).                                |
| `hue`             | `number`            | `0`               | Hue rotation in degrees (-180 to 180).                                 |
| `saturation`      | `number`            | `1`               | Saturation multiplier (0 to 2).                                        |
| `brightness`      | `number`            | `1`               | Brightness multiplier (0.35 to 1.65).                                  |
| `color`           | `string`            | depends on `mode` | Node and link colour; `#E6C879` in dark mode, `#8B6914` in light mode. |
| `backgroundColor` | `string`            | depends on `mode` | Scene background; `#070914` in dark mode, `#eef1f6` in light mode.     |
