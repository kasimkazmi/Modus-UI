title: Ignition Button
description: A WebGL launch button whose starfield warps into hyperspace on hover and flashes white on click.
---

A raw-WebGL button over a drifting ambient noise field. Hovering primes the core so the stars stretch into warp streaks, and clicking fires a white flash. It fills its positioned parent, pauses when off screen or when the tab is hidden, and holds a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="ignition-button" />

## Installation

### CLI

```bash
npx @modus-ui/cli add ignition-button
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/ignition-button.tsx`.
3. Paste the code.

## Usage

```tsx
import { IgnitionButton } from "@/components/ui/ignition-button";

export default function Example() {
  return (
    <div className="relative h-[400px] w-full overflow-hidden">
      <IgnitionButton />
    </div>
  );
}
```

## Props

| Prop              | Type                                   | Default     | Description                                                                                  |
| :---------------- | :------------------------------------- | :---------- | :------------------------------------------------------------------------------------------- |
| `label`           | `string`                               | `"LAUNCH"`  | Button text.                                                                                 |
| `mode`            | `"dark" \| "light"`                    | `"dark"`    | Scene theme. The backdrop shader is colour-inverted when the mode differs from the original. |
| `hue`             | `number`                               | `0`         | Hue rotation in degrees (-180 to 180).                                                       |
| `saturation`      | `number`                               | `1`         | Saturation multiplier (0 to 2).                                                              |
| `brightness`      | `number`                               | `1`         | Brightness multiplier (0.35 to 1.65).                                                        |
| `darkBackground`  | `string`                               | `"#121316"` | Scene colour in dark mode.                                                                   |
| `lightBackground` | `string`                               | `"#f0ede7"` | Scene colour in light mode.                                                                  |
| `onClick`         | `ButtonHTMLAttributes["onClick"]`      | -           | Called after the button's own click effect.                                                  |
| `onMouseEnter`    | `ButtonHTMLAttributes["onMouseEnter"]` | -           | Called after the button's own mouse enter effect.                                            |
| `onMouseLeave`    | `ButtonHTMLAttributes["onMouseLeave"]` | -           | Called after the button's own mouse leave effect.                                            |
| `onFocus`         | `ButtonHTMLAttributes["onFocus"]`      | -           | Called after the button's own focus effect.                                                  |
| `onBlur`          | `ButtonHTMLAttributes["onBlur"]`       | -           | Called after the button's own blur effect.                                                   |

Any other `<button>` attribute is passed through to the inner button.
