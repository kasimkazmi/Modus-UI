title: Orbit Gallery

Sixteen curved image panels arranged in a helix around a cylinder, rotating slowly and floating up and down over a light dotted backdrop. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="orbit-gallery" />

## Installation

### CLI

```bash
npx @modus-ui/cli add orbit-gallery
```

### Manual

1. Install `three`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/orbit-gallery.tsx`.
4. Paste the code.

## Usage

```tsx
import { OrbitGallery } from "@/components/ui/orbit-gallery";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <OrbitGallery />
      <div className="relative z-10 p-8">
        <h1>Content over the effect</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type       | Default                    | Description                                  |
| :---------------- | :--------- | :------------------------- | :------------------------------------------- |
| `images`          | `string[]` | five sample photos         | Image URLs, repeated across the 16 panels.   |
| `speed`           | `number`   | `1`                        | Rotation speed, clamped to 0–3.              |
| `scale`           | `number`   | `1`                        | Scale of the helix, clamped to 0.7–1.35.     |
| `opacity`         | `number`   | `1`                        | Canvas opacity, clamped to 0.05–1.           |
| `hue`             | `number`   | `0`                        | Hue rotation in degrees, clamped to ±180.    |
| `saturation`      | `number`   | `1`                        | CSS saturation filter, clamped to 0–2.       |
| `brightness`      | `number`   | `1`                        | CSS brightness filter, clamped to 0.35–1.65. |
| `backgroundColor` | `string`   | `"#f1f1ef"`                | Background colour.                           |
| `dotColor`        | `string`   | `"rgba(13, 13, 13, 0.13)"` | Colour of the background dot grid.           |
