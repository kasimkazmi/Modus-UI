A canvas wireframe that turns in 3D with depth-faded edges and bright vertex points. Choose a stellated cube, two interlocking cylinders or a nested icosahedron. It pauses when off screen and draws a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="wireframe-form" />

## Installation

### CLI

```bash
npx @modus-ui/cli add wireframe-form
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/wireframe-form.tsx`.
3. Paste the code.

## Usage

```tsx
import { WireframeForm } from "@/components/ui/wireframe-form";

export default function Example() {
  return (
    <div className="flex min-h-[400px] items-center justify-center bg-[#050505]">
      <WireframeForm variant="sphere" />
    </div>
  );
}
```

## Props

| Prop         | Type                                | Default  | Description                                                      |
| :----------- | :---------------------------------- | :------- | :--------------------------------------------------------------- |
| `variant`    | `"cube" \| "cylinders" \| "sphere"` | `"cube"` | Which form to draw.                                              |
| `mode`       | `"dark" \| "light"`                 | `"dark"` | White ink for dark surfaces, dark ink for light ones.            |
| `speed`      | `number`                            | `1`      | Rotation speed multiplier (0 to 3).                              |
| `size`       | `number`                            | `1`      | Line width multiplier.                                           |
| `length`     | `number`                            | `1`      | Scale of the form itself (0.35 to 2.5).                          |
| `opacity`    | `number`                            | `1`      | Opacity of the canvas.                                           |
| `hue`        | `number`                            | `0`      | Hue rotation in degrees.                                         |
| `saturation` | `number`                            | `1`      | Saturation multiplier.                                           |
| `brightness` | `number`                            | `1`      | Brightness multiplier.                                           |
| `color`      | `string`                            | none     | Ink colour as hex; white in dark mode, near-black in light mode. |
