A verlet sheet of letters hanging from five pegs, swaying in a breeze. Letters stretch and rotate with the weave; grab the sheet and pull. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="cloth-study" />

## Installation

### CLI

```bash
npx @modus-ui/cli add cloth-study
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/cloth-study.tsx`.
3. Paste the code.

## Usage

```tsx
import { ClothStudy } from "@/components/ui/cloth-study";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <ClothStudy />
    </div>
  );
}
```

## Props

| Prop              | Type                | Default                                                                                | Description                                 |
| :---------------- | :------------------ | :------------------------------------------------------------------------------------- | :------------------------------------------ |
| `text`            | `string`            | `"thefabricremembersthelineitwasgivenandkeepsonsayingitwhilethewindpullsatthecorners"` | Phrase woven into the sheet.                |
| `mode`            | `"dark" \| "light"` | `"dark"`                                                                               | Colour scheme of the ground and ink.        |
| `scale`           | `number`            | `1`                                                                                    | Scales the drawing (clamped 0.65–1.5).      |
| `opacity`         | `number`            | `1`                                                                                    | Overall opacity (clamped 0.1–1).            |
| `hue`             | `number`            | `0`                                                                                    | Hue rotation in degrees (clamped -180–180). |
| `saturation`      | `number`            | `1`                                                                                    | Saturation multiplier (clamped 0–2).        |
| `brightness`      | `number`            | `1`                                                                                    | Brightness multiplier (clamped 0.4–1.8).    |
| `inkColor`        | `string`            | Mode ink (`#e2e4e9` dark, `#262830` light)                                             | Colour of the type, as hex.                 |
| `backgroundColor` | `string`            | Mode ground (`#08090a` dark, `#f3f5f8` light)                                          | Background colour.                          |
