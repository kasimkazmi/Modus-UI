## Installation

### CLI

```bash
npx @modus-ui/cli add root-nav
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/root-nav.tsx`.
3. Paste the code.

## Usage

```tsx
import { RootNav } from "@/components/ui/root-nav";

export default function Example() {
  return <RootNav />;
}
```
