---
title: Dot Border Button
description: An outline button that draws a dashed frame, corner dots and a hatch fill around itself on hover.
---

An outline button on a dark stage. On hover it fills indigo, widens its letter spacing, and four dots fly out to the corners while dashed lines draw a frame and a diagonal hatch fades in behind. Hue, saturation and brightness grade the button with a CSS filter, and the motion is switched off when the user prefers reduced motion. The component fills its parent and paints its own stage, so give it a sized container. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add dot-border-button
```

### Manual

1. Install `framer-motion`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/dot-border-button.tsx`.
4. Paste the code.

## Usage

```tsx
import { DotBorderButton } from "@/components/ui/dot-border-button";

export default function Example() {
  return (
    <div className="h-[300px] w-full">
      <DotBorderButton onClick={() => console.log("clicked")} />
    </div>
  );
}
```

## Props

| Prop         | Type                                   | Default            | Description                                                                         |
| :----------- | :------------------------------------- | :----------------- | :---------------------------------------------------------------------------------- |
| `mode`       | `"light" \| "dark"`                    | `"dark"`           | Stage background and ink.                                                           |
| `label`      | `string`                               | `"Start Creating"` | Button text.                                                                        |
| `hue`        | `number`                               | `0`                | Hue rotation in degrees, clamped to -180 to 180.                                    |
| `saturation` | `number`                               | `1`                | Saturation multiplier, clamped to 0 to 2.                                           |
| `brightness` | `number`                               | `1`                | Brightness multiplier, clamped to 0.35 to 1.65.                                     |
| `background` | `string`                               | `undefined`        | Stage background; falls back to `#111318` in dark mode and `#f4f7fb` in light mode. |
| `onClick`    | `MouseEventHandler<HTMLButtonElement>` | `undefined`        | Click handler.                                                                      |
