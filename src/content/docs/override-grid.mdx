A block-by-block grid that pulses outward from the centre in telemetry orange. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="override-grid" />

## Installation

### CLI

```bash
npx @modus-ui/cli add override-grid
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/override-grid.tsx`.
3. Paste the code.

## Usage

```tsx
import { OverrideGrid } from "@/components/ui/override-grid";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <OverrideGrid />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type                | Default           | Description                   |
| :---------------- | :------------------ | :---------------- | :---------------------------- |
| `mode`            | `"dark" \| "light"` | `"dark"`          | Colour scheme.                |
| `speed`           | `number`            | `1`               | Animation speed multiplier.   |
| `size`            | `number`            | `48`              | Block size in pixels.         |
| `gap`             | `number`            | `2`               | Gap between blocks in pixels. |
| `opacity`         | `number`            | `1`               | Canvas opacity.               |
| `hue`             | `number`            | `0`               | Hue rotation in degrees.      |
| `saturation`      | `number`            | `1`               | Saturation multiplier.        |
| `brightness`      | `number`            | `1`               | Brightness multiplier.        |
| `color`           | `string`            | depends on `mode` | Hex colour of the blocks.     |
| `backgroundColor` | `string`            | depends on `mode` | Background colour.            |
