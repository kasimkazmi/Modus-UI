---
title: Bell Field
description: A WebGL shader background of a struck bell's vibration modes in patina and bronze, with drifting embers.
---

A full-bleed WebGL shader that traces the nodal lines of a vibrating bell as it drifts between partials, over a dark patina field with drifting embers. The bell strikes every few seconds and on every click, sending out a shock ring, and the pattern leans toward the pointer. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add bell-field
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/bell-field.tsx`.
3. Paste the code.

## Usage

```tsx
import { BellField } from "@/components/ui/bell-field";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <BellField />
      <div className="relative z-10 p-8 text-white">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type       | Default         | Description                                                                       |
| :---------------- | :--------- | :-------------- | :-------------------------------------------------------------------------------- |
| `speed`           | `number`   | `1`             | Animation speed multiplier.                                                       |
| `pointerAmount`   | `number`   | `1`             | How far the pattern follows the pointer.                                          |
| `strikeDuration`  | `number`   | `2400`          | Milliseconds a strike's shock ring takes to fade.                                 |
| `emberAmount`     | `number`   | `1`             | Share of the 58 drifting embers to draw (0 to 1).                                 |
| `brightness`      | `number`   | `1`             | CSS brightness filter.                                                            |
| `opacity`         | `number`   | `1`             | Overall opacity.                                                                  |
| `hue`             | `number`   | `0`             | Hue rotation in degrees.                                                          |
| `saturation`      | `number`   | `1`             | CSS saturation filter.                                                            |
| `backgroundColor` | `string`   | `"#08100f"`     | Scene background colour.                                                          |
| `colors`          | `string[]` | ThreeUI palette | Shader colours: deep, patina (nodal lines), bronze (antinodes), ash (highlights). |
| `emberColors`     | `string[]` | ThreeUI palette | Ember colours: hot, cool.                                                         |
