---
title: Liquid Metal Button
description: A WebGL2 button whose face pours into prismatic liquid metal on hover, with ripples on press.
---

A dispersion shader paints laminar rainbow ribbons inside the pill on hover, a travelling chromatic rim runs round the outline, the cursor drags the metal and each press throws a faceted ripple. Comes as a labelled pill, an icon circle or a larger play circle. Pauses when off screen; with reduced motion the metal holds still. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add liquid-metal-button
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/liquid-metal-button.tsx`.
3. Paste the code.

## Usage

```tsx
import { LiquidMetalButton } from "@/components/ui/liquid-metal-button";

export default function Example() {
  return (
    <div className="h-[400px] w-full">
      <LiquidMetalButton text="Sign up" />
    </div>
  );
}
```

## Props

| Prop          | Type                           | Default                               | Description                                             |
| :------------ | :----------------------------- | :------------------------------------ | :------------------------------------------------------ |
| `variant`     | `"pill" \| "circle" \| "play"` | `"pill"`                              | Labelled pill, icon-only circle, or larger play circle. |
| `rendering`   | `"colored" \| "monotone"`      | `"colored"`                           | Play variant only: full colour or greyscale metal.      |
| `diameter`    | `number`                       | `88`                                  | Play variant only: diameter in px (72 to 160).          |
| `strokeWidth` | `number`                       | `3`                                   | Play variant only: rim stroke width in px (1 to 8).     |
| `text`        | `string`                       | "Sign up", "Add" or "Play" by variant | Pill label, or the accessible name.                     |
| `embedded`    | `boolean`                      | `false`                               | Use a flat dark ground instead of the ambient pool.     |
| `onClick`     | `() => void`                   | —                                     | Click handler.                                          |
