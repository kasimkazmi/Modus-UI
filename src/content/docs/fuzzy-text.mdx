---
title: Fuzzy Text
description: Typography rendered with dynamic, animated noise and grain displacement.
---

A completely custom `<canvas>` based typography component ported from React Bits. It reads the raw pixels of drawn text and randomly offsets them every frame using an intensity scale, creating a highly unique "fuzzy" or distorted aesthetic.

<ComponentPreview name="fuzzy-text" />

## Installation

### CLI

```bash
npx @modus-ui/cli add fuzzy-text
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/fuzzy-text.tsx`.
3. Paste the code.

## Usage

```tsx
import { FuzzyText } from "@/components/ui/fuzzy-text";

export default function Example() {
  return <FuzzyText hoverIntensity={0.8}>Hello</FuzzyText>;
}
```

## Props

| Prop             | Type               | Default                    | Description                                     |
| :--------------- | :----------------- | :------------------------- | :---------------------------------------------- |
| `fontSize`       | `number \| string` | `"clamp(3rem, 8vw, 6rem)"` | Font size (number in pixels or any CSS length). |
| `fontWeight`     | `number \| string` | `900`                      | Font weight.                                    |
| `fontFamily`     | `string`           | `"inherit"`                | Font family.                                    |
| `color`          | `string`           | `"hsl(var(--foreground))"` | Text colour.                                    |
| `enableHover`    | `boolean`          | `true`                     | Increases the fuzz while the text is hovered.   |
| `baseIntensity`  | `number`           | `0.18`                     | Fuzz intensity at rest.                         |
| `hoverIntensity` | `number`           | `0.6`                      | Fuzz intensity while hovered.                   |
