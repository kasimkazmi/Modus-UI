A premium HTML5 Canvas-based background animation. Technical circuit lines grow, branch off, and fade, while pointer hover and clicks trigger smooth, natural water ripples that respond to current theme modes.

<ComponentPreview name="circuit-background" />

## Installation

### CLI

```bash
npx react-ui-component add circuit-background
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/circuit-background.tsx`.
3. Paste the code.

## Usage

```tsx
import { CircuitBackground } from "@/components/ui/circuit-background";

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <div className="relative min-h-screen">
      <CircuitBackground />
      <main className="relative z-10">{children}</main>
    </div>
  );
}
```

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `maxTrails` | `number` | `60` | The maximum amount of concurrently active growing circuits. |
| `lineColor` | `string` | - | Custom stroke color for circuit lines. (Defaults to theme-adapted colors). |
| `circleColor` | `string` | - | Custom border color for connection node circles. (Defaults to theme-adapted colors). |
| `glowStrength` | `number` | `6` | Glow shadow size in pixels. |
| `circleSize` | `number` | `5` | Radius of the circuit connection nodes. |
| `spawnChance` | `number` | `0.03` | Probability of spawning a new circuit line per frame. |
| `className` | `string` | - | Additional CSS class for the canvas containers. |
