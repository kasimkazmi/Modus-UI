## Installation

### CLI

```bash
npx @modus-ui/cli add lattice-loader
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/lattice-loader.tsx`.
3. Paste the code.

```tsx

export default function Example() {
```
