---
title: Intro Wordmark
description: A keynote-style wordmark that assembles letter by letter with chromatic fringes, then holds and loops.
---

Each letter flies in from a seeded offset with red, green and blue fringes that converge as it lands, while a round mark scales in beside the word. The finished wordmark holds, then the intro replays. It scales to fill its parent, pauses off screen and shows the finished wordmark when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add intro-wordmark
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/intro-wordmark.tsx`.
3. Paste the code.

## Usage

```tsx
import { IntroWordmark } from "@/components/ui/intro-wordmark";

export default function Example() {
  return (
    <div className="relative h-[400px] w-full">
      <IntroWordmark text="Modus UI" />
    </div>
  );
}
```

## Props

| Prop              | Type      | Default      | Description                                            |
| :---------------- | :-------- | :----------- | :----------------------------------------------------- |
| `text`            | `string`  | `"Modus UI"` | Wordmark text that assembles.                          |
| `showMark`        | `boolean` | `true`       | Show the round mark before the text.                   |
| `color`           | `string`  | `"#f5f5f7"`  | Text and mark colour.                                  |
| `backgroundColor` | `string`  | `"#000000"`  | Scene background.                                      |
| `fontSize`        | `number`  | `130`        | Font size of the wordmark on the 1280×720 composition. |
| `duration`        | `number`  | `1.7`        | Seconds the assemble animation runs.                   |
| `holdTime`        | `number`  | `1.1`        | Seconds the finished wordmark holds before looping.    |
