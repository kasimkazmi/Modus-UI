Three circular icon buttons. Play is dark glass with an orbiting sheen and a hover bloom, plus is a raised amber cap that presses down, and mail draws a staged dotted frame around itself on hover. Ported from ThreeUI Community (MIT).

<ComponentPreview name="circle-button" />

## Installation

### CLI

```bash
npx @modus-ui/cli add circle-button
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/circle-button.tsx`.
3. Paste the code.

## Usage

```tsx
import { CircleButton } from "@/components/ui/circle-button";

export default function Example() {
  return (
    <div className="h-[400px] w-full">
      <CircleButton variant="mail" />
    </div>
  );
}
```

## Props

| Prop         | Type                                   | Default                                 | Description                            |
| :----------- | :------------------------------------- | :-------------------------------------- | :------------------------------------- |
| `variant`    | `"play" \| "plus" \| "mail"`           | `"play"`                                | Which button to render.                |
| `mode`       | `"dark" \| "light"`                    | `"dark"`                                | Ground the button is toned for.        |
| `hue`        | `number`                               | `0`                                     | Hue rotation in degrees (-180 to 180). |
| `saturation` | `number`                               | `1`                                     | Saturation multiplier (0 to 2).        |
| `brightness` | `number`                               | `1`                                     | Brightness multiplier (0.35 to 1.65).  |
| `ariaLabel`  | `string`                               | "Play", "Add" or "Send mail" by variant | Accessible label.                      |
| `disabled`   | `boolean`                              | `false`                                 | Disables the button.                   |
| `type`       | `"button" \| "submit" \| "reset"`      | `"button"`                              | Native button type.                    |
| `onClick`    | `MouseEventHandler<HTMLButtonElement>` | —                                       | Click handler for the button.          |
