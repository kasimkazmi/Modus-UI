---
title: Paper Mill
description: A list of cards you drag into a slot that cuts them into falling strips.
---

Built for discarding drafts with a little ceremony: the slot and strips take the foreground ink, and the cards are whatever you render. Reordering and keyboard delete are built in.

<ComponentPreview name="paper-mill" />

## Installation

### CLI

```bash
npx @modus-ui/cli add paper-mill
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/paper-mill.tsx`.
3. Paste the code.

## Usage

```tsx
import { PaperMill } from "@/components/ui/paper-mill";

export default function Example() {
  return <PaperMill />;
}
```
