title: Sliding Text CTA
description: A dark pill whose label blurs away downward while a copy slides in from above on hover.
---

A neutral dark pill. On hover the button lifts, the label slides down and blurs out while a copy slides in from above, and a soft underline and bottom glow brighten. Hue, saturation and brightness grade the button with a CSS filter, and the motion is switched off when the user prefers reduced motion. The component fills its parent and paints its own stage, so give it a sized container. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add sliding-text-cta
```

### Manual

1. Install `framer-motion`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/sliding-text-cta.tsx`.
4. Paste the code.

## Usage

```tsx
import { SlidingTextCta } from "@/components/ui/sliding-text-cta";

export default function Example() {
  return (
    <div className="h-[300px] w-full">
      <SlidingTextCta onClick={() => console.log("clicked")} />
    </div>
  );
}
```

## Props

| Prop         | Type                                   | Default              | Description                                                                         |
| :----------- | :------------------------------------- | :------------------- | :---------------------------------------------------------------------------------- |
| `mode`       | `"light" \| "dark"`                    | `"dark"`             | Stage background and ink.                                                           |
| `label`      | `string`                               | `"Download Mac app"` | Button text.                                                                        |
| `hue`        | `number`                               | `0`                  | Hue rotation in degrees, clamped to -180 to 180.                                    |
| `saturation` | `number`                               | `1`                  | Saturation multiplier, clamped to 0 to 2.                                           |
| `brightness` | `number`                               | `1`                  | Brightness multiplier, clamped to 0.35 to 1.65.                                     |
| `background` | `string`                               | `undefined`          | Stage background; falls back to `#111318` in dark mode and `#f4f7fb` in light mode. |
| `onClick`    | `MouseEventHandler<HTMLButtonElement>` | `undefined`          | Click handler.                                                                      |
