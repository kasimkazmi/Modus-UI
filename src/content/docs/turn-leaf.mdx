---
title: Turn Leaf
description: A paper leaf you drag, click or key-press to turn over, with a soft tilt and sheen.
---

Turn Leaf presents two faces, recto and verso, on a bordered card-coloured sheet. It tilts toward the pointer, turns with spring physics when dragged or pressed, and fades instead of rotating under reduced motion. Ported from React Bits and restyled for Modus.

<ComponentPreview name="turn-leaf" />

## Installation

### CLI

```bash
npx @modus-ui/cli add turn-leaf
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/turn-leaf.tsx`.
3. Paste the code.

## Usage

```tsx
import { TurnLeaf } from "@/components/ui/turn-leaf";

export default function Example() {
  return <TurnLeaf />;
}
```

## Props

| Prop           | Type    | Default                  | Description                                                      |
| :------------- | :------ | :----------------------- | :--------------------------------------------------------------- |
| front          | any     | null                     | Content of the front face.                                       |
| back           | any     | null                     | Content of the back face.                                        |
| flipped        | any     | -                        | Controlled flipped state.                                        |
| defaultFlipped | boolean | false                    | Initial flipped state when uncontrolled.                         |
| onFlipChange   | any     | -                        | Called with the new flipped state.                               |
| axis           | string  | "y"                      | Axis the leaf turns around: "x" or "y".                          |
| flipOnClick    | boolean | true                     | Turn the leaf on click.                                          |
| draggable      | boolean | true                     | Allow turning the leaf by dragging.                              |
| dragDistance   | number  | 0                        | Drag distance in pixels to commit a turn; 0 uses half the width. |
| tilt           | boolean | true                     | Tilt the leaf toward the pointer on hover.                       |
| tiltMax        | number  | 8                        | Maximum hover tilt in degrees.                                   |
| glare          | boolean | true                     | Show a moving glare highlight.                                   |
| glareOpacity   | number  | 0.22                     | Opacity of the glare highlight.                                  |
| hoverScale     | number  | 1.03                     | Scale applied on hover.                                          |
| perspective    | number  | 1100                     | CSS perspective in pixels.                                       |
| stiffness      | number  | 170                      | Spring stiffness of the turn.                                    |
| damping        | number  | 20                       | Spring damping of the turn.                                      |
| width          | number  | 280                      | Leaf width in pixels.                                            |
| height         | number  | 380                      | Leaf height in pixels.                                           |
| radius         | number  | 10                       | Corner radius in pixels.                                         |
| background     | string  | "hsl(var(--card))"       | Face background colour.                                          |
| color          | string  | "hsl(var(--foreground))" | Face text colour.                                                |
| shadow         | boolean | true                     | Show a drop shadow.                                              |
| shadowColor    | string  | "hsl(var(--foreground))" | Drop shadow colour.                                              |
| shadowOpacity  | number  | 0.3                      | Drop shadow opacity.                                             |
| disabled       | boolean | false                    | Disables turning and tilt.                                       |
| ariaLabel      | string  | "Turn leaf"              | Accessible label for the leaf.                                   |
