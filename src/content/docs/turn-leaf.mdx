---
title: Turn Leaf
description: A paper leaf you drag, click or key-press to turn over, with a soft tilt and sheen.
---

Turn Leaf presents two faces, recto and verso, on a bordered card-coloured sheet. It tilts toward the pointer, turns with spring physics when dragged or pressed, and fades instead of rotating under reduced motion. Ported from React Bits and restyled for Modus.

<ComponentPreview name="turn-leaf" />

## Installation

### CLI

```bash
npx @modus-ui/cli add turn-leaf
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/turn-leaf.tsx`.
3. Paste the code.

## Usage

```tsx
import { TurnLeaf } from "@/components/ui/turn-leaf";

export default function Example() {
  return <TurnLeaf />;
}
```
