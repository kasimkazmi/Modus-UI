---
title: Ink Rush
description: Rounded ink strokes rushing out of a high vanishing point, in the theme ink and accent.
---

Two hundred rounded strokes fly out of a vanishing point set high in the frame, mixing `--foreground`, `--muted-foreground` and `--primary` and leaving short trails that fade into `--background`. In light mode it reads as ink on paper; it follows palette and mode changes live. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion.

<ComponentPreview name="ink-rush" />

## Installation

### CLI

```bash
npx @modus-ui/cli add ink-rush
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/ink-rush.tsx`.
3. Paste the code.

## Usage

```tsx
import { InkRush } from "@/components/ui/ink-rush";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <InkRush />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type     | Default              | Description                                         |
| :---------------- | :------- | :------------------- | :-------------------------------------------------- |
| `speed`           | `number` | `1`                  | Animation speed multiplier (0–3).                   |
| `size`            | `number` | `1`                  | Field-of-view scale multiplier.                     |
| `length`          | `number` | `1`                  | Length / reach multiplier (0.35–2.5).               |
| `density`         | `number` | `1`                  | Streak count multiplier. (0.25–2.5).                |
| `opacity`         | `number` | `1`                  | Opacity of the effect layer (0.05–1).               |
| `hue`             | `number` | `0`                  | Hue rotation in degrees applied to the final frame. |
| `saturation`      | `number` | `1`                  | Saturation multiplier applied to the final frame.   |
| `brightness`      | `number` | `1`                  | Brightness multiplier applied to the final frame.   |
| `backgroundColor` | `string` | theme `--background` | Background colour behind the canvas.                |
