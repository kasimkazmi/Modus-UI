A night sky over layered parallax ridges, with twinkling stars and the occasional meteor, steered by the pointer. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="cloud-field" />

## Installation

### CLI

```bash
npx @modus-ui/cli add cloud-field
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/cloud-field.tsx`.
3. Paste the code.

## Usage

```tsx
import { CloudField } from "@/components/ui/cloud-field";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <CloudField />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type     | Default     | Description                                     |
| :---------------- | :------- | :---------- | :---------------------------------------------- |
| `speed`           | `number` | `1`         | Animation speed multiplier.                     |
| `hue`             | `number` | `0`         | Hue rotation in degrees.                        |
| `saturation`      | `number` | `1`         | Saturation multiplier.                          |
| `brightness`      | `number` | `1`         | Brightness multiplier.                          |
| `backgroundColor` | `string` | `"#071010"` | Colour shown behind the canvas before it draws. |
