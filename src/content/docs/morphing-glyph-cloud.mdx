---
title: Morphing Glyph Cloud
description: A cloud of glyphs filling one SVG mark that morphs into another on click.
---

Two marks sharing a cloud of glyphs, paired by angle so the change reads as a turn. Click to morph, hover to push the glyphs aside. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="morphing-glyph-cloud" />

## Installation

### CLI

```bash
npx @modus-ui/cli add morphing-glyph-cloud
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/morphing-glyph-cloud.tsx`.
3. Paste the code.

## Usage

```tsx
import { MorphingGlyphCloud } from "@/components/ui/morphing-glyph-cloud";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <MorphingGlyphCloud />
    </div>
  );
}
```

## Props

| Prop              | Type                | Default                                                                                      | Description                                        |
| :---------------- | :------------------ | :------------------------------------------------------------------------------------------- | :------------------------------------------------- |
| `fromPath`        | `string`            | `"M12 0C12.9 7 17 11.1 24 12C17 12.9 12.9 17 12 24C11.1 17 7 12.9 0 12C7 11.1 11.1 7 12 0Z"` | SVG path data (24×24 viewBox) of the resting mark. |
| `toPath`          | `string`            | `"M12 2a10 10 0 1 1 0 20a10 10 0 1 1 0-20Zm0 5a5 5 0 1 0 0 10a5 5 0 1 0 0-10Z"`              | SVG path data (24×24 viewBox) it morphs into.      |
| `mode`            | `"dark" \| "light"` | `"dark"`                                                                                     | Colour scheme of the ground and ink.               |
| `scale`           | `number`            | `1`                                                                                          | Scales the drawing (clamped 0.65–1.5).             |
| `opacity`         | `number`            | `1`                                                                                          | Overall opacity (clamped 0.1–1).                   |
| `hue`             | `number`            | `0`                                                                                          | Hue rotation in degrees (clamped -180–180).        |
| `saturation`      | `number`            | `1`                                                                                          | Saturation multiplier (clamped 0–2).               |
| `brightness`      | `number`            | `1`                                                                                          | Brightness multiplier (clamped 0.4–1.8).           |
| `inkColor`        | `string`            | Mode ink (`#e2e4e9` dark, `#262830` light)                                                   | Colour of the type, as hex.                        |
| `backgroundColor` | `string`            | Mode ground (`#08090a` dark, `#f3f5f8` light)                                                | Background colour.                                 |
