Hundreds of tapered strokes fan out rightward from a source just off the left edge, thickening as they travel, in the theme's primary with muted tails and foreground tips. It fills its positioned parent, follows the active theme and palette in light and dark mode, pauses when off screen and renders a still frame when the user prefers reduced motion.

<ComponentPreview name="ink-fountain" />

## Installation

### CLI

```bash
npx @modus-ui/cli add ink-fountain
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/ink-fountain.tsx`.
3. Paste the code.

## Usage

```tsx
import { InkFountain } from "@/components/ui/ink-fountain";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <InkFountain />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type     | Default     | Description                                         |
| :---------------- | :------- | :---------- | :-------------------------------------------------- |
| `speed`           | `number` | `0.7`       | Animation speed multiplier (0–3).                   |
| `size`            | `number` | `0.8`       | Stroke width multiplier.                            |
| `length`          | `number` | `1.2`       | Stroke length multiplier (0.35–2.5).                |
| `density`         | `number` | `0.8`       | Stroke count multiplier (0.25–2.5).                 |
| `opacity`         | `number` | `1`         | Opacity of the effect layer (0.05–1).               |
| `hue`             | `number` | `0`         | Hue rotation in degrees applied to the final frame. |
| `saturation`      | `number` | `1`         | Saturation multiplier applied to the final frame.   |
| `brightness`      | `number` | `1`         | Brightness multiplier applied to the final frame.   |
| `backgroundColor` | `string` | `undefined` | CSS background. Defaults to the theme background.   |
