---
title: Paper Stack
description: A paper sleeve that fans out draggable note slips when opened.
---

Paper Stack holds a set of short notes behind a serif-labelled sleeve. Hover or click to open it and the slips rise out as mono-set tags that can be dragged and picked. Every surface comes from the Modus theme tokens. Ported from React Bits and restyled for Modus.

<ComponentPreview name="paper-stack" />

## Installation

### CLI

```bash
npx @modus-ui/cli add paper-stack
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/paper-stack.tsx`.
3. Paste the code.

## Usage

```tsx
import { PaperStack } from "@/components/ui/paper-stack";

export default function Example() {
  return <PaperStack />;
}
```
