A full-bleed WebGL sphere of rotating violet smoke with a glowing rim, over a deep indigo sky of drifting, twinkling stars. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="energy-orb" />

## Installation

### CLI

```bash
npx @modus-ui/cli add energy-orb
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/energy-orb.tsx`.
3. Paste the code.

## Usage

```tsx
import { EnergyOrb } from "@/components/ui/energy-orb";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <EnergyOrb />
      <div className="relative z-10 p-8 text-white">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type     | Default     | Description                              |
| :---------------- | :------- | :---------- | :--------------------------------------- |
| `speed`           | `number` | `1`         | Rotation speed multiplier.               |
| `scale`           | `number` | `1`         | Scale of the orb canvas.                 |
| `smokeScale`      | `number` | `1`         | Size of the smoke detail.                |
| `smokeStrength`   | `number` | `1`         | Brightness of the smoke veil.            |
| `smokeSpeed`      | `number` | `1`         | Speed of the smoke flow.                 |
| `hue`             | `number` | `0`         | Hue rotation in degrees (orb and stars). |
| `saturation`      | `number` | `1`         | Orb colour saturation.                   |
| `glow`            | `number` | `1`         | Strength of the rim and outer glow.      |
| `starDensity`     | `number` | `1`         | Star count multiplier.                   |
| `starSpeed`       | `number` | `1`         | Star drift speed.                        |
| `starSize`        | `number` | `1`         | Star size multiplier.                    |
| `brightness`      | `number` | `1`         | CSS brightness filter on the orb.        |
| `opacity`         | `number` | `1`         | Orb opacity.                             |
| `backgroundColor` | `string` | `"#05030e"` | Scene background colour.                 |
