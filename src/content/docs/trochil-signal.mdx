A hairline glass rectangle on a near-black stage with an amber glow. On hover an amber sheen sweeps across it and the border warms. The component fills its parent and paints its own stage, so give it a sized container. Animations and transitions are turned off when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="trochil-signal" />

## Installation

### CLI

```bash
npx @modus-ui/cli add trochil-signal
```

### Manual

1. Install `framer-motion`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/trochil-signal.tsx`.
4. Paste the code.

## Usage

```tsx
import { TrochilSignal } from "@/components/ui/trochil-signal";

export default function Example() {
  return (
    <div className="h-[300px] w-full">
      <TrochilSignal onClick={() => console.log("clicked")} />
    </div>
  );
}
```

## Props

| Prop      | Type                                   | Default            | Description               |
| :-------- | :------------------------------------- | :----------------- | :------------------------ |
| `label`   | `string`                               | `"Request access"` | Button text.              |
| `mode`    | `"dark" \| "light"`                    | `"dark"`           | Stage and button palette. |
| `type`    | `"button" \| "submit" \| "reset"`      | `"button"`         | Native button type.       |
| `onClick` | `MouseEventHandler<HTMLButtonElement>` | `undefined`        | Click handler.            |
