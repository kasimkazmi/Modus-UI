---
title: Predictive Arc
description: A violet dotted arch whose dots swell and shimmer in moving waves on a black background.
---

A 2D canvas samples a wide arch on a dot grid; each dot grows with its distance to the curve and shimmers in crossing waves, blended additively from violet edges to white-hot cores on black. Set `mode="light"` for violet ink on pale paper. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add predictive-arc
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/predictive-arc.tsx`.
3. Paste the code.

## Usage

```tsx
import { PredictiveArc } from "@/components/ui/predictive-arc";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <PredictiveArc />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type                | Default           | Description                                                           |
| :---------------- | :------------------ | :---------------- | :-------------------------------------------------------------------- |
| `mode`            | `"dark" \| "light"` | `"dark"`          | Colour scheme: additive violet on black, or violet ink on pale paper. |
| `speed`           | `number`            | `1`               | Wave speed multiplier.                                                |
| `spacing`         | `number`            | `5`               | Grid spacing between dots in pixels.                                  |
| `dotSize`         | `number`            | `6`               | Maximum dot size in pixels.                                           |
| `archHeight`      | `number`            | `0.7`             | How far the arch falls toward the sides, as a fraction of the height. |
| `thickness`       | `number`            | `1`               | Thickness multiplier of the arch band.                                |
| `brightness`      | `number`            | `1`               | Dot brightness multiplier.                                            |
| `hue`             | `number`            | `0`               | Hue rotation in degrees.                                              |
| `saturation`      | `number`            | `1`               | Saturation multiplier.                                                |
| `backgroundColor` | `string`            | depends on `mode` | Scene background; `#030303` in dark mode, `#eef1f6` in light mode.    |
