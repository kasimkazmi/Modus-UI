A full-bleed WebGL shader of a laser beam through drifting fog that tilts toward the pointer. Pick between the atmospheric blade, a vanishing array of rays, a prism aperture and a halftone relay. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="laser" />

## Installation

### CLI

```bash
npx @modus-ui/cli add laser
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/laser.tsx`.
3. Paste the code.

## Usage

```tsx
import { Laser } from "@/components/ui/laser";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <Laser />
      <div className="relative z-10 p-8 text-white">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type                                                                                                         | Default               | Description                           |
| :---------------- | :----------------------------------------------------------------------------------------------------------- | :-------------------- | :------------------------------------ |
| `variant`         | `"matrix-field"` \| `"atmospheric-blade"` \| `"vanishing-array"` \| `"prism-aperture"` \| `"halftone-relay"` | `"atmospheric-blade"` | Which laser scene to draw.            |
| `speed`           | `number`                                                                                                     | `1`                   | Animation speed (0 to 3).             |
| `size`            | `number`                                                                                                     | `1`                   | Beam width (0.35 to 2.5).             |
| `length`          | `number`                                                                                                     | `1`                   | Beam length (0.35 to 2.5).            |
| `density`         | `number`                                                                                                     | `1`                   | Fog and detail density (0.25 to 2.5). |
| `opacity`         | `number`                                                                                                     | `1`                   | Canvas opacity (0.05 to 1).           |
| `hue`             | `number`                                                                                                     | `0`                   | Hue shift in degrees (-180 to 180).   |
| `saturation`      | `number`                                                                                                     | `1`                   | Colour saturation (0 to 2).           |
| `brightness`      | `number`                                                                                                     | `1`                   | Brightness (0.35 to 1.65).            |
| `backgroundColor` | `string`                                                                                                     | `"#020305"`           | Background behind the canvas.         |
