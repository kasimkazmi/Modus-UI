title: Ribbon Field
description: A WebGL shader background of glowing teal and violet ribbons drawn through a halftone dot grid.
---

A full-bleed WebGL shader of undulating teal, cyan and violet ribbons rendered through a scanning halftone dot grid, fading to black on the left so text reads cleanly. The ribbons drift with the pointer. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="ribbon-field" />

## Installation

### CLI

```bash
npx @modus-ui/cli add ribbon-field
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/ribbon-field.tsx`.
3. Paste the code.

## Usage

```tsx
import { RibbonField } from "@/components/ui/ribbon-field";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <RibbonField />
      <div className="relative z-10 p-8 text-white">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type       | Default         | Description                                              |
| :---------------- | :--------- | :-------------- | :------------------------------------------------------- |
| `speed`           | `number`   | `1`             | Animation speed multiplier.                              |
| `pointerAmount`   | `number`   | `1`             | How strongly the ribbons follow the pointer.             |
| `smoothing`       | `number`   | `0.035`         | Pointer easing per frame.                                |
| `brightness`      | `number`   | `1`             | CSS brightness filter.                                   |
| `opacity`         | `number`   | `1`             | Canvas opacity.                                          |
| `hue`             | `number`   | `0`             | Hue rotation in degrees.                                 |
| `saturation`      | `number`   | `1`             | CSS saturation filter.                                   |
| `backgroundColor` | `string`   | `"#010101"`     | Base colour behind the ribbons.                          |
| `colors`          | `string[]` | ThreeUI palette | Ribbon colours: teal, cyan, indigo, purple, blue, bloom. |
