---
title: Hum Capsule
description: A dictation button that opens into a capsule with a live level meter and a running clock.
---

At rest it is a soft muted square in foreground ink; while listening it widens and its meter and timer take the primary token. Slide left to cancel, or hold to talk.

<ComponentPreview name="hum-capsule" />

## Installation

### CLI

```bash
npx @modus-ui/cli add hum-capsule
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/hum-capsule.tsx`.
3. Paste the code.

## Usage

```tsx
import { HumCapsule } from "@/components/ui/hum-capsule";

export default function Example() {
  return <HumCapsule />;
}
```
