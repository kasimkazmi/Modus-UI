title: Steady Press
description: A press-and-hold confirm button that fills from below with a wavy crest.
---

Steady Press guards a deliberate action: hold it and a primary tint rises with a wave on its crest until the action completes. Letting go early drains it. Mono uppercase label on a secondary surface. Ported from React Bits and restyled for Modus.

<ComponentPreview name="steady-press" />

## Installation

### CLI

```bash
npx @modus-ui/cli add steady-press
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/steady-press.tsx`.
3. Paste the code.

## Usage

```tsx
import { SteadyPress } from "@/components/ui/steady-press";

export default function Example() {
  return <SteadyPress />;
}
```
