---
title: Ember Hint
description: An inverted ink tooltip that stays warm, so moving between triggers glides from one label to the next.
---

Labels are small uppercase mono on a foreground slab, matching the theme in light and dark. After the first one opens, neighbours show instantly and the tooltip travels across. Wrap triggers in `EmberHintGroup` to share that warm state.

<ComponentPreview name="ember-hint" />

## Installation

### CLI

```bash
npx @modus-ui/cli add ember-hint
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/ember-hint.tsx`.
3. Paste the code.

## Usage

```tsx
import { EmberHint } from "@/components/ui/ember-hint";

export default function Example() {
  return (
    <EmberHint content="Bold">
      <button>Bold</button>
    </EmberHint>
  );
}
```
