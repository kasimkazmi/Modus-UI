---
title: Uplink Loader
description: A green terminal-style progress loader with a ticked bar, glowing readout and phase labels.
---

A 56-tick progress bar fills through a scripted run, lighting each tick with a flash while a neon percentage readout flickers above it and a status line steps through its phases. Scanlines, film grain and a glitch on each restart finish the look. It scales a 1200×800 stage to fit its parent, pauses off screen and shows a still frame at 50% when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add uplink-loader
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/uplink-loader.tsx`.
3. Paste the code.

## Usage

```tsx
import { UplinkLoader } from "@/components/ui/uplink-loader";

export default function Example() {
  return (
    <div className="relative h-[400px] w-full">
      <UplinkLoader label="UPLINK" />
    </div>
  );
}
```

## Props

| Prop              | Type                 | Default                            | Description                                                    |
| :---------------- | :------------------- | :--------------------------------- | :------------------------------------------------------------- |
| `label`           | `string`             | `"UPLINK"`                         | Label above the progress bar.                                  |
| `phases`          | `[number, string][]` | five uplink phases from 0% to 100% | Status lines, each shown from its percentage threshold upward. |
| `duration`        | `number`             | `8600`                             | Duration of the 0 → 100 run, in milliseconds.                  |
| `color`           | `string`             | `"#2fe07d"`                        | Accent green.                                                  |
| `backgroundColor` | `string`             | `"#030806"`                        | Scene background.                                              |
