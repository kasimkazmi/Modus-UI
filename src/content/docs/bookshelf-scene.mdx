title: Bookshelf Scene
description: A Three.js room with a carousel shelf of seven cloth-bound volumes that retints the room to each book.
---

A walnut shelf of seven foil-stamped volumes in a softly lit room. Drag, scroll or click to move the carousel; the wall, floor and light shift to the selected book's palette, and clicking the centred volume opens it for inspection with orbit controls and turnable pages. Covers and the shelf wood are drawn procedurally unless you pass your own images. It fills its positioned parent, pauses when off screen or when the tab is hidden and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add bookshelf-scene
```

### Manual

1. Install `three`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/bookshelf-scene.tsx`.
4. Paste the code.

## Usage

```tsx
import { BookshelfScene } from "@/components/ui/bookshelf-scene";

export default function Example() {
  return (
    <div className="relative h-[600px] w-full overflow-hidden">
      <BookshelfScene />
    </div>
  );
}
```

## Props

| Prop              | Type     | Default     | Description                                                                                           |
| :---------------- | :------- | :---------- | :---------------------------------------------------------------------------------------------------- |
| `coverAtlas`      | `string` | none        | Image URL of seven 512×768 covers side by side (3584×768). Without it, covers are drawn procedurally. |
| `woodTexture`     | `string` | none        | Image URL for the shelf wood (must allow CORS). Without it, a walnut grain is drawn procedurally.     |
| `backgroundColor` | `string` | `"#171a24"` | Colour behind the canvas while it loads.                                                              |
