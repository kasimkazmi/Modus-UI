A photoreal instrument dial built from CSS: a screwed mounting plate, knurled bezel, printed scale with coloured zones, a sprung needle and cover glass. When it scrolls into view it runs an instrument self-test (full-scale sweep, fall back, settle on the live reading) and repeats every eight seconds. It renders the settled reading without motion when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add performance-gauge
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/performance-gauge.tsx`.
3. Paste the code.

## Usage

```tsx
import { PerformanceGauge } from "@/components/ui/performance-gauge";

export default function Example() {
  return (
    <div className="flex items-center justify-center bg-black p-8">
      <PerformanceGauge variant="boost" className="max-w-[340px]" />
    </div>
  );
}
```

## Props

| Prop         | Type                                                  | Default        | Description                                    |
| :----------- | :---------------------------------------------------- | :------------- | :--------------------------------------------- |
| `variant`    | `"tachometer" \| "speedometer" \| "boost" \| "power"` | `"tachometer"` | Which instrument to render.                    |
| `hue`        | `number`                                              | `0`            | Hue rotation applied to the gauge, in degrees. |
| `saturation` | `number`                                              | `1`            | Saturation multiplier applied to the gauge.    |
| `brightness` | `number`                                              | `1`            | Brightness multiplier applied to the gauge.    |
