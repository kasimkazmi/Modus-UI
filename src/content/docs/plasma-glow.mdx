An animated plasma field with a bloom pass, a touch of chromatic aberration and a dark vignette. It fills its positioned parent and freezes its animation when the user prefers reduced motion. Built on the [shaders](https://shaders.com) library (MIT) and rendered with WebGPU.

<ComponentPreview name="plasma-glow" />

## Installation

### CLI

```bash
npx @modus-ui/cli add plasma-glow
```

### Manual

1. Install `shaders` with `npm install shaders`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/plasma-glow.tsx`.
4. Paste the code.

## Usage

```tsx
import { PlasmaGlow } from "@/components/ui/plasma-glow";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <PlasmaGlow />
      <div className="relative z-10 p-8">
        <h1>Content over the effect</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop         | Type     | Default     | Description                    |
| :----------- | :------- | :---------- | :----------------------------- |
| `colorA`     | `string` | `"#0b0221"` | Dark plasma colour.            |
| `colorB`     | `string` | `"#ff3fa4"` | Bright plasma colour.          |
| `speed`      | `number` | `1`         | Animation speed.               |
| `density`    | `number` | `1`         | Density of the plasma bands.   |
| `warp`       | `number` | `1`         | Amount of domain warping.      |
| `glow`       | `number` | `0.6`       | Bloom intensity.               |
| `aberration` | `number` | `0.3`       | Chromatic aberration strength. |
