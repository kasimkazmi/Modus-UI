A thermal orange gradient button with a chevron, on a dark stage with a soft heat glow. It lifts and brightens on hover and presses down when clicked. The component fills its parent and paints its own stage, so give it a sized container. Animations and transitions are turned off when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="attune-thermal" />

## Installation

### CLI

```bash
npx @modus-ui/cli add attune-thermal
```

### Manual

1. Install `framer-motion`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/attune-thermal.tsx`.
4. Paste the code.

## Usage

```tsx
import { AttuneThermal } from "@/components/ui/attune-thermal";

export default function Example() {
  return (
    <div className="h-[300px] w-full">
      <AttuneThermal onClick={() => console.log("clicked")} />
    </div>
  );
}
```

## Props

| Prop      | Type                                   | Default        | Description               |
| :-------- | :------------------------------------- | :------------- | :------------------------ |
| `label`   | `string`                               | `"Start free"` | Button text.              |
| `mode`    | `"dark" \| "light"`                    | `"dark"`       | Stage and button palette. |
| `type`    | `"button" \| "submit" \| "reset"`      | `"button"`     | Native button type.       |
| `onClick` | `MouseEventHandler<HTMLButtonElement>` | `undefined`    | Click handler.            |
