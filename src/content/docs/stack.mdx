An interactive deck of cards utilizing Framer Motion's `useTransform` and `drag`. Cards can be thrown to the back of the stack by dragging them off-center, or by clicking them (configurable).

<ComponentPreview name="stack" />

## Installation

### CLI

```bash
npx @modus-ui/cli add stack
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/stack.tsx`.
3. Paste the code.

## Usage

```tsx
import { Stack } from "@/components/ui/stack";

export default function Example() {
  const cards = [
    <div key="1" className="h-full w-full rounded-2xl bg-blue-500">
      Card 1
    </div>,
    <div key="2" className="h-full w-full rounded-2xl bg-red-500">
      Card 2
    </div>,
  ];

  return (
    <div className="h-[400px] w-[300px]">
      <Stack cards={cards} randomRotation={true} sendToBackOnClick={true} />
    </div>
  );
}
```

## Props

| Prop                | Type                                     | Default                           | Description                                              |
| :------------------ | :--------------------------------------- | :-------------------------------- | :------------------------------------------------------- |
| `cards`             | `React.ReactNode[]`                      | -                                 | The cards in the stack.                                  |
| `randomRotation`    | `boolean`                                | `false`                           | Gives each card a slight random rotation.                |
| `sensitivity`       | `number`                                 | `200`                             | Drag distance in pixels that sends a card to the back.   |
| `animationConfig`   | `{ stiffness: number; damping: number }` | `{ stiffness: 260, damping: 20 }` | Spring settings for card movement.                       |
| `sendToBackOnClick` | `boolean`                                | `false`                           | Sends the top card to the back on click.                 |
| `autoplay`          | `boolean`                                | `false`                           | Cycles the cards automatically.                          |
| `autoplayDelay`     | `number`                                 | `3000`                            | Milliseconds between automatic cycles.                   |
| `pauseOnHover`      | `boolean`                                | `false`                           | Pauses autoplay while hovered.                           |
| `mobileClickOnly`   | `boolean`                                | `false`                           | Uses click instead of drag on mobile.                    |
| `mobileBreakpoint`  | `number`                                 | `768`                             | Width in pixels below which the device counts as mobile. |
