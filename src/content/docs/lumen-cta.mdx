The authored Lumen call-to-action on its own indigo stage. The primary variant is a pill with a near-black to violet gradient, a soft violet glow and a ring glyph, and brightens on hover. The ghost variant is the same pill in frosted glass. Hue, saturation and brightness grade the button with a CSS filter, and the hover transition is switched off when the user prefers reduced motion. The component fills its parent and paints Lumen's background, so give it a sized container. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add lumen-cta
```

### Manual

1. Install `framer-motion`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/lumen-cta.tsx`.
4. Paste the code.

## Usage

```tsx
import { LumenCta } from "@/components/ui/lumen-cta";

export default function Example() {
  return (
    <div className="h-[300px] w-full">
      <LumenCta label="Get started" onClick={() => console.log("clicked")} />
    </div>
  );
}
```

## Props

| Prop         | Type                                   | Default           | Description                                                                         |
| :----------- | :------------------------------------- | :---------------- | :---------------------------------------------------------------------------------- |
| `variant`    | `"primary" \| "ghost"`                 | `"primary"`       | Gradient pill or frosted glass pill.                                                |
| `mode`       | `"light" \| "dark"`                    | `"dark"`          | Stage background and ghost ink.                                                     |
| `label`      | `string`                               | `"Get your card"` | Button text.                                                                        |
| `ring`       | `boolean`                              | `true`            | Shows the small ring glyph after the label.                                         |
| `hue`        | `number`                               | `0`               | Hue rotation in degrees, clamped to -180 to 180.                                    |
| `saturation` | `number`                               | `1`               | Saturation multiplier, clamped to 0 to 2.                                           |
| `brightness` | `number`                               | `1`               | Brightness multiplier, clamped to 0.35 to 1.65.                                     |
| `disabled`   | `boolean`                              | `false`           | Disables the button.                                                                |
| `type`       | `"button" \| "submit" \| "reset"`      | `"button"`        | Native button type.                                                                 |
| `onClick`    | `MouseEventHandler<HTMLButtonElement>` | `undefined`       | Click handler.                                                                      |
| `background` | `string`                               | `undefined`       | Stage background; falls back to `#0b0821` in dark mode and `#f3f0fb` in light mode. |
