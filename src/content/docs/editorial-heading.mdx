description: A field-notes list whose article headings decode from scrambled glyphs into their titles.
---

ThreeUI's Article Headings: a numbered field-notes list on a grainy near-black page. On mount each heading decodes left to right, one after another. A short band of scrambled glyphs leads the reveal while a few characters further along flicker, then the title settles. Type scales with the container, the meta column drops away on narrow screens, and headings appear as-is when the user prefers reduced motion. The component fills its parent, so give it a sized container. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add editorial-heading
```

### Manual

1. Install `framer-motion`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/editorial-heading.tsx`.
4. Paste the code.

## Usage

```tsx
import { EditorialHeading } from "@/components/ui/editorial-heading";

export default function Example() {
  return (
    <div className="h-[420px] w-full">
      <EditorialHeading
        entries={[
          { title: "Context Is Infrastructure", meta: "SYSTEMS NOTE · 8 MIN" },
          { title: "The Last Mile Is Verification", meta: "FIELD GUIDE · 11 MIN" },
        ]}
      />
    </div>
  );
}
```

## Props

| Prop             | Type                                | Default                 | Description                                         |
| :--------------- | :---------------------------------- | :---------------------- | :-------------------------------------------------- |
| `mode`           | `"dark" \| "light"`                 | `"dark"`                | Page palette.                                       |
| `duration`       | `number`                            | `560`                   | Length of each decode in milliseconds.              |
| `stagger`        | `number`                            | `140`                   | Delay between headings in milliseconds.             |
| `scrambleLength` | `number`                            | `10`                    | Number of scrambled glyphs leading the reveal.      |
| `preserveChance` | `number`                            | `0.3`                   | Chance a leading glyph shows its real character.    |
| `tailChance`     | `number`                            | `0.18`                  | Chance an unrevealed character flickers to a glyph. |
| `label`          | `string`                            | `"FIELD NOTES"`         | Header caption on the left.                         |
| `entries`        | `{ title: string; meta: string }[]` | The two ThreeUI entries | Rows to list; each is numbered automatically.       |
