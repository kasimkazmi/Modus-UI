title: Emerald Horizon

A full-bleed Three.js shader of a glowing emerald band that undulates along the bottom edge, shifting between green tones and fading into black under a soft vignette. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="emerald-horizon" />

## Installation

### CLI

```bash
npx @modus-ui/cli add emerald-horizon
```

### Manual

1. Install `three`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/emerald-horizon.tsx`.
4. Paste the code.

## Usage

```tsx
import { EmeraldHorizon } from "@/components/ui/emerald-horizon";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <EmeraldHorizon />
      <div className="relative z-10 p-8">
        <h1>Content over the effect</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type               | Default                | Description                                             |
| :---------------- | :----------------- | :--------------------- | :------------------------------------------------------ |
| `speed`           | `number`           | `1`                    | Animation speed multiplier.                             |
| `waveScale`       | `number`           | `1`                    | Height of the horizon waves.                            |
| `variation`       | `number`           | `1`                    | Strength of the brightness variation along the horizon. |
| `glow`            | `number`           | `1`                    | Glow intensity.                                         |
| `vignette`        | `number`           | `1`                    | Vignette strength, from 0 (off) to 1.                   |
| `hue`             | `number`           | `0`                    | Hue rotation in degrees.                                |
| `colors`          | `[string, string]` | the two ThreeUI greens | The two glow colours blended across the horizon.        |
| `backgroundColor` | `string`           | `"#000500"`            | Colour of the sky above the glow.                       |
