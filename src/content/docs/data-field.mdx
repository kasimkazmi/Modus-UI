Sixty additive Three.js lines tilted into a plane and rolled by two layered waves, in warm neutral tones. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="data-field" />

## Installation

### CLI

```bash
npx @modus-ui/cli add data-field
```

### Manual

1. Install `three`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/data-field.tsx`.
4. Paste the code.

## Usage

```tsx
import { DataField } from "@/components/ui/data-field";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <DataField />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type                | Default     | Description                            |
| :---------------- | :------------------ | :---------- | :------------------------------------- |
| `mode`            | `"dark" \| "light"` | `"dark"`    | Colour scheme hint for the effect.     |
| `hue`             | `number`            | `0`         | Hue rotation in degrees (-180 to 180). |
| `saturation`      | `number`            | `1`         | Saturation multiplier (0 to 2).        |
| `brightness`      | `number`            | `1`         | Brightness multiplier (0.35 to 1.65).  |
| `startColor`      | `string`            | `"#D1C5B4"` | Colour of the first line in the field. |
| `endColor`        | `string`            | `"#7A7B76"` | Colour of the last line in the field.  |
| `backgroundColor` | `string`            | `"#050505"` | Colour behind the effect.              |
