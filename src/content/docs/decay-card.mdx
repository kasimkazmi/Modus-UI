---
title: Decay Card
description: A 3D interactive card that decays and shatters its visual elements when hovered.
---

A highly complex and interactive SVG filter component ported from React Bits. It uses `feTurbulence` and `feDisplacementMap` bound to the cursor's movement distance to mathematically "shatter" the underlying image, while physics calculations handle the 3D rotation and translation. Completely refactored from GSAP to pure React + requestAnimationFrame for zero dependencies!

<ComponentPreview name="decay-card" />

## Installation

### CLI

```bash
npx @modus-ui/cli add decay-card
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/decay-card.tsx`.
3. Paste the code.

## Usage

```tsx
import { DecayCard } from "@/components/ui/decay-card";

export default function Example() {
  return (
    <DecayCard image="/your-image.jpg">
      <h2>Hover Me</h2>
    </DecayCard>
  );
}
```

## Props

| Prop              | Type     | Default                                                                                          | Description                                                      |
| :---------------- | :------- | :----------------------------------------------------------------------------------------------- | :--------------------------------------------------------------- |
| `width`           | `number` | `300`                                                                                            | Card width in pixels.                                            |
| `height`          | `number` | `400`                                                                                            | Card height in pixels.                                           |
| `image`           | `string` | `"https://images.unsplash.com/photo-1707584102941-c11438a2e1d7?q=80&w=600&auto=format&fit=crop"` | Image URL.                                                       |
| `baseFrequency`   | `number` | `0.015`                                                                                          | Base frequency of the turbulence filter.                         |
| `numOctaves`      | `number` | `5`                                                                                              | Octaves of the turbulence filter.                                |
| `seed`            | `number` | `4`                                                                                              | Seed of the turbulence filter.                                   |
| `maxDisplacement` | `number` | `400`                                                                                            | Maximum displacement of the distortion.                          |
| `movementBound`   | `number` | `50`                                                                                             | Distance in pixels the card follows the cursor before resisting. |
