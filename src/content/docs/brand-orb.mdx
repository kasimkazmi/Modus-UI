A small canvas orb that renders a brand mark as z-sorted, softly lit dots and keeps it gently moving, ideal next to a "Thinking…" status label. Pick one of 23 brands, two sizes and a dark or light mode. It pauses when off screen or the tab is hidden and draws a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="brand-orb" />

## Installation

### CLI

```bash
npx @modus-ui/cli add brand-orb
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/brand-orb.tsx`.
3. Paste the code.

## Usage

```tsx
import { BrandOrb } from "@/components/ui/brand-orb";

export default function Example() {
  return (
    <div className="h-14 w-14">
      <BrandOrb brand="openai" />
    </div>
  );
}
```

Available brands: `claude`, `openai`, `codex`, `cursor`, `gemini`, `figma`, `framer`, `react`, `swift`, `designcode`, `aura`, `dreamcut`, `ui`, `ux`, `css`, `ios`, `neuform`, `github`, `x`, `instagram`, `threads`, `linkedin`, `email`.

## Props

| Prop              | Type                                                                                                                                                                                                                                                                                                              | Default                                          | Description                                      |
| :---------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------- | :----------------------------------------------- |
| `brand`           | `"claude"` \| `"openai"` \| `"codex"` \| `"cursor"` \| `"gemini"` \| `"figma"` \| `"framer"` \| `"react"` \| `"swift"` \| `"designcode"` \| `"aura"` \| `"dreamcut"` \| `"ui"` \| `"ux"` \| `"css"` \| `"ios"` \| `"neuform"` \| `"github"` \| `"x"` \| `"instagram"` \| `"threads"` \| `"linkedin"` \| `"email"` | `"claude"`                                       | Which brand mark to animate.                     |
| `size`            | `"small" \| "medium"`                                                                                                                                                                                                                                                                                             | `"medium"`                                       | `small` renders a 20px orb, `medium` a 56px orb. |
| `mode`            | `"dark" \| "light"`                                                                                                                                                                                                                                                                                               | `"dark"`                                         | `light` inverts the orb for light surfaces.      |
| `speed`           | `number`                                                                                                                                                                                                                                                                                                          | `1`                                              | Animation speed multiplier, clamped to 0.1–3.    |
| `paused`          | `boolean`                                                                                                                                                                                                                                                                                                         | `false`                                          | Freezes the animation on its current frame.      |
| `backgroundColor` | `string`                                                                                                                                                                                                                                                                                                          | Near-black in dark mode, warm grey in light mode | Surface colour behind the orb.                   |
