A Three.js flight through a corridor of coloured streaks. The `streaks` variant adds luminous tiles, `letters` tumbling glyphs, `keycaps` lit keyboard caps and sparks, and `hyperspace` a blue tunnel with a pulsing core glow. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add warp-field
```

### Manual

1. Install `three`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/warp-field.tsx`.
4. Paste the code.

## Usage

```tsx
import { WarpField } from "@/components/ui/warp-field";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <WarpField />
      <div className="relative z-10 p-8">
        <h1>Content over the effect</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type                                                  | Default                | Description                                       |
| :---------------- | :---------------------------------------------------- | :--------------------- | :------------------------------------------------ |
| `variant`         | `"streaks" \| "letters" \| "keycaps" \| "hyperspace"` | `"streaks"`            | Which corridor to fly through.                    |
| `speed`           | `number`                                              | `15`                   | Distance travelled per frame.                     |
| `streakOpacity`   | `number`                                              | `0.6`                  | Opacity of the streaks (and keycap sparks).       |
| `tileOpacity`     | `number`                                              | `0.9`                  | Opacity of the tiles, letters, keycaps or tunnel. |
| `fov`             | `number`                                              | `75`                   | Camera field of view in degrees.                  |
| `brightness`      | `number`                                              | `1`                    | CSS brightness filter.                            |
| `hue`             | `number`                                              | `0`                    | Hue rotation in degrees.                          |
| `saturation`      | `number`                                              | `1`                    | CSS saturation filter.                            |
| `colors`          | `string[]`                                            | the variant palette    | Streak colours.                                   |
| `backgroundColor` | `string`                                              | the variant background | Scene and fog colour.                             |
