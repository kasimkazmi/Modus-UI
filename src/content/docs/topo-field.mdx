---
title: Topo Field
description: A WebGL topographic contour map drifting over a fine pixel grid.
---

A WebGL fragment shader draws thin contour lines over simplex noise that slowly drifts across a 48px grid. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="topo-field" />

## Installation

### CLI

```bash
npx @modus-ui/cli add topo-field
```

### Manual

1. Copy the code from the component tab.
2. Create a file at `components/ui/topo-field.tsx`.
3. Paste the code.

## Usage

```tsx
import { TopoField } from "@/components/ui/topo-field";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <TopoField />
      <div className="relative z-10 p-8">
        <h1>Content over the background</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type                | Default         | Description                                                                      |
| :---------------- | :------------------ | :-------------- | :------------------------------------------------------------------------------- |
| `mode`            | `"dark" \| "light"` | `"dark"`        | Colour scheme of the original dark and light versions.                           |
| `speed`           | `number`            | `1`             | Animation speed multiplier (0–3).                                                |
| `length`          | `number`            | `1`             | Length / reach multiplier (0.35–2.5).                                            |
| `density`         | `number`            | `1`             | Contour band count multiplier. (0.25–2.5).                                       |
| `opacity`         | `number`            | `1`             | Opacity of the effect layer (0.05–1).                                            |
| `hue`             | `number`            | `0`             | Hue rotation in degrees applied to the final frame.                              |
| `saturation`      | `number`            | `1`             | Saturation multiplier applied to the final frame.                                |
| `brightness`      | `number`            | `1`             | Brightness multiplier applied to the final frame.                                |
| `backgroundColor` | `string`            | mode background | Background colour behind the canvas (defaults to `#000000` in its default mode). |
