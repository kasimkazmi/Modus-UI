A full-bleed Three.js shader of dots that swell and fade in diagonal waves on a dark stage, fading out toward the edges and shifting slightly as the pointer moves anywhere over the page. It fills its positioned parent, pauses when off screen and renders a still frame when the user prefers reduced motion. Ported from ThreeUI Community (MIT).

<ComponentPreview name="dot-matrix" />

## Installation

### CLI

```bash
npx @modus-ui/cli add dot-matrix
```

### Manual

1. Install `three`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/dot-matrix.tsx`.
4. Paste the code.

## Usage

```tsx
import { DotMatrix } from "@/components/ui/dot-matrix";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <DotMatrix />
      <div className="relative z-10 p-8">
        <h1>Content over the effect</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop              | Type     | Default     | Description                               |
| :---------------- | :------- | :---------- | :---------------------------------------- |
| `speed`           | `number` | `1`         | Animation speed multiplier.               |
| `gridScale`       | `number` | `60`        | Number of dot cells across the height.    |
| `mouseAmount`     | `number` | `0.04`      | How far the grid shifts with the pointer. |
| `pulseSpeed`      | `number` | `0.4`       | Speed of the pulse wave.                  |
| `radius`          | `number` | `0.15`      | Extra dot radius at the peak of a pulse.  |
| `opacity`         | `number` | `0.35`      | Overall opacity of the dots.              |
| `hue`             | `number` | `0`         | Hue rotation in degrees.                  |
| `color`           | `string` | `"#00e6ff"` | Dot colour at the peak of a pulse.        |
| `backgroundColor` | `string` | `"#030304"` | Background behind the dots.               |
