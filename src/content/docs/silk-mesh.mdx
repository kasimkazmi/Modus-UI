title: Silk Mesh

A drifting mesh gradient whose colours default to your theme's background and primary tokens, textured with soft-light noise and film grain. Colours update when the theme changes. It fills its positioned parent and freezes its animation when the user prefers reduced motion. Built on the [shaders](https://shaders.com) library (MIT) and rendered with WebGPU.

<ComponentPreview name="silk-mesh" />

## Installation

### CLI

```bash
npx @modus-ui/cli add silk-mesh
```

### Manual

1. Install `shaders` with `npm install shaders`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/silk-mesh.tsx`.
4. Paste the code.

## Usage

```tsx
import { SilkMesh } from "@/components/ui/silk-mesh";

export default function Example() {
  return (
    <div className="relative h-[500px] w-full overflow-hidden">
      <SilkMesh />
      <div className="relative z-10 p-8">
        <h1>Content over the effect</h1>
      </div>
    </div>
  );
}
```

## Props

| Prop         | Type     | Default     | Description                                         |
| :----------- | :------- | :---------- | :-------------------------------------------------- |
| `colorA`     | `string` | theme token | First colour. Defaults to the `--background` token. |
| `colorB`     | `string` | theme token | Second colour. Defaults to the `--primary` token.   |
| `speed`      | `number` | `0.6`       | Drift speed.                                        |
| `count`      | `number` | `4`         | Number of colour swaths.                            |
| `swirl`      | `number` | `0.5`       | Amount of swirl in the swaths.                      |
| `smoothness` | `number` | `0.6`       | Softness of the seams between swaths.               |
| `grain`      | `number` | `0.06`      | Film grain strength.                                |
