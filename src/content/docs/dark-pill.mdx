A dark glass pill on a charcoal stage. A blurred conic highlight orbits inside the pill and gives way to a soft light pool on hover, and the pill presses in slightly on click. Light mode turns the smoked glass frosted on a paper stage. The orbit and hover transitions stop when the user prefers reduced motion. The component fills its parent and paints its own stage, so give it a sized container. Ported from ThreeUI Community (MIT).

## Installation

### CLI

```bash
npx @modus-ui/cli add dark-pill
```

### Manual

1. Install `framer-motion`.
2. Copy the code from the component tab.
3. Create a file at `components/ui/dark-pill.tsx`.
4. Paste the code.

## Usage

```tsx
import { DarkPill } from "@/components/ui/dark-pill";

export default function Example() {
  return (
    <div className="h-[300px] w-full">
      <DarkPill onClick={() => console.log("clicked")} />
    </div>
  );
}
```

## Props

| Prop         | Type                                   | Default     | Description                                                                         |
| :----------- | :------------------------------------- | :---------- | :---------------------------------------------------------------------------------- |
| `mode`       | `"light" \| "dark"`                    | `"dark"`    | Stage and glass treatment.                                                          |
| `label`      | `string`                               | `"Sign up"` | Button text.                                                                        |
| `background` | `string`                               | `undefined` | Stage background; falls back to `#0a0a0a` in dark mode and `#eeedeb` in light mode. |
| `onClick`    | `MouseEventHandler<HTMLButtonElement>` | `undefined` | Click handler.                                                                      |
